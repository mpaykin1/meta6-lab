# INK · Долина пробуждения — 12 новых анимированных 3D-ассетов

Эталон, только чтение: `reference/ink-fallen-guardian/`. Движок акварели импортируется напрямую из эталона. Новые makers оригинальные и не изменяют объекты эталона.

Игровая сцена: `index.html`; 12 авторских 3D-объектов собираются в `makers.js` по списку `ZAKAZ.json`.
Управление: WASD/стрелки, джойстик на телефоне, вращение камеры пальцем; ☰ — выбор ассета. Колокол и шестерня подсвечивают сцену и уменьшают туман при приближении.
Небо, лес, берег, озеро, многоуровневая дымка, дождь, свет и рельеф созданы в `index.html`.
Включены экономия рендера при низком FPS, детерминированные семена, `window.__ISOLATE__(id,on)` для сравнения каждого ассета с эталоном. Защищённые файлы эталона не меняются.

Дальше: визуальное сравнение с несколькими ассетами эталона, снимок `_check/compare.png`, браузерный замер FPS и независимая приёмка до слияния.

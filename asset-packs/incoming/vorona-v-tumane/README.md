# Ворона в тумане

Игра-сцена 2.5D из оригинальных акварельных рисунков META GAMES (ворона PNG и 16-кадровое существо GIF). Оригиналы лежат в `reference/vorona-v-tumane/` и не изменяются.

**Запуск:** `index.html` через веб-сервер из корня репозитория. Локальная Three.js лежит в `reference/ink-fallen-guardian/three.module.js`; внешних CDN нет.

**Управление:** стрелки/WASD — полёт; касание/клик — полёт к точке; на телефоне — экранные кнопки. Перо ускоряет, светлячок подсвечивает туман, гнездо сохраняет точку возвращения, существо сбивает и возвращает героя. Звук включается после пользовательского действия.

**Состав:** 26 пунктов `ZAKAZ.json`: 3 слоя леса, GPU-туман и капли, 8 шарнирных сегментов вороны, 10 сегментов существа, новые обитатели леса, находки, события и 5 оригинальных Web Audio эффектов. `cutout.json` — реальные полигоны исходных рисунков и точки шарниров.

**Приёмка:** `automation/asset-check/kinds/cutout.py` проверяет исходное изображение, форму масок, иерархию и запаздывающую анимацию; `cutout_browser.mjs` проверяет WebGL в Chrome. В `ready/` переводить только после нуля HARD и визуального принятия.

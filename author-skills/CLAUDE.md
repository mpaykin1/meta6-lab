# Claude Code — Авторские игровые скилы

Работай только в `author-skills/` ветки `lab/author-skills-source-20261121`; не изменяй `main`, `meta6`, `.github/`, защитные правила, ядро бота и эталонные игры.

Здесь размещены исходники девяти авторских плагинов. У каждого читай оригинальный `skills/<slug>/SKILL.md`, сопровождающие скрипты, лицензии и примеры; не делай вывод о полной работоспособности только по декларации в инструкциях.

Для восстановления оригинальных моделей/текстур используй `import_original_assets.py` и три официальных архива их собственных релизов. Отсутствующие ассеты нельзя подменять заглушками или приблизительными копиями. Манифест `original-assets.manifest.json` перечисляет необходимые бинарные файлы.

Цель интеграции: полностью анимированные игровые сцены с крупной, логичной, плавной амплитудой движений всех персонажей; отдельная анимация поз/кадров без деформации оригинального рисунка; неизменная внешность героя между состояниями; никаких незапрошенных действий героя; стрелки, клавиши и сенсорное управление; полная высота экрана и поддержка портретной и альбомной ориентации; стабильный WebGL и управление FPS. Проверяй запуск в реальном браузере, но не называй ничего PASS без подтверждения. Выход — работающая графика и анимация в самой игре, не отчёты.

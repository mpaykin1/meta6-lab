# Three-VRM — official upstream integration

- GitHub https://github.com/pixiv/three-vrm; package `@pixiv/three-vrm@3.5.5`, MIT (copyright pixiv 2019–2026). The editor used to make VRM assets is independent and not bundled.
- Source: https://github.com/pixiv/three-vrm/tree/v3.5.5; VRM 1.0 spec https://github.com/vrm-c/vrm-specification.
- Bundled original `models/pastel-scout.vrm` is generated from `scripts/make_sample_vrm.py` (pure Python). It contains glTF 2.0 + VRMC_vrm 1.0, 16 mapped humanoid bones and two eyes bound to `blink` via glTF morph targets. Art is original; no borrowed or licensed character meshes.
- Default game mascot stays the same Blockbench bunny `.glb`. The HERO command explicitly loads the optional VRM, ↑ VRM imports a `.vrm` from the player's device, and WAVE/BLINK are the only actions. Do not replace a model on idle, attack or loop; one loaded VRM instance is used for all gestures and expressions.
- Runtime: `vrm-avatar.js` imports upstream `VRMLoaderPlugin`, registers it with Three's `GLTFLoader`, checks `gltf.userData.vrm?.humanoid`, and exposes an update(dt) that calls `vrm.update(dt)` in the game's existing frame loop (never another requestAnimationFrame). Bone gestures use the existing Tween.js Group. `VRMExpressionManager.setValue('blink', value)` is used only when the expression exists; otherwise BLINK is disabled.
- One skeleton at a time in the mascot stage. Previous avatar stays displayed if loading fails. Prior avatar resources are released only after the new VRM is parsed, never on a failed import. No texture/collider substitutions. VRM author licenses and permissions remain applicable for user-imported characters; their rights are not granted by Three-VRM's MIT license.
- Rapier still owns rigid-body physics only for balls/fragment colliders; Three-VRM handles humanoid bones/expressions and optional spring bones. Tween animates presentation but never dynamic Rapier bodies. The shared render loop still drives Three.quarks particles and postprocessing Bloom.
- Import map: `@pixiv/three-vrm` -> pinned CDN `https://cdn.jsdelivr.net/npm/@pixiv/three-vrm@3.5.5/lib/three-vrm.module.js` (requires internet). `scripts/vendor_engines.py` downloads the official npm package to `vendor/three-vrm.module.js` and verifies SHA-512 before rewriting import map for offline play.
- Do not run geometry simplification, skeleton merging, morph pruning or Meshopt quantization on a VRM unless separately validated for humanoid bones and expressions. Keep source `.vrm` untouched.

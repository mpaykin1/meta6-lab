# HERO ANIMATOR — НЕИЗМЕННЫЙ СПРАЙТ И ОТДЕЛЬНЫЕ ПОКАДРОВЫЕ РИСУНКИ

**Обязательный, неотключаемый запрет.** Любое движение ЛЮБОГО человека, животного, NPC или героя запрещено имитировать деформацией одной фотографии или иллюстрации. Запрещены `cv2.remap`, `warpAffine`, `warpPerspective`, mesh warp, optical flow, RIFE для персонажей, skeleton/puppet cutout и сгибание фрагментов исходного изображения. Плавная деформация лица, хвоста, головы или руки **НЕ** является анимацией. Никакой эффектор, постобработка, генерация одинаковых кадров, global bob/scale/rotation, смещение вырезанной головы вместо движения тела, параллакс, раскачивание карточки не засчитываются.

## Единственный разрешённый метод для персонажей

1. Канонический персонаж: утвердить reference sheet, одежду, лицо, силуэт, габариты, palette, unique `hero_id`. Не заменять персонажа другим. Не зеркалить асимметричную внешность.
2. Для каждого действия и требуемого ракурса создать **отдельную последовательность полноценных отрисованных RGBA PNG поз** (`idle`, `walk`, `run`, `sit`, `stand`, `eat`, `talk`, `pour`, `read`, `wave`, `groom`, `sleep`, `wake`, `jump`, `dodge`, `roll`, `attack` и др. по роли). В каждой PNG весь персонаж отрисован заново в выбранной позе; не применять к исходному растру нелинейные искажения. Для качества 8–16 или больше оригинальных кадров на действие при 8–16 fps спрайта; при недостатке промежуточных кадров **дорисовывать отдельные**, а не создавать flow-смещения или transform-синтез.
3. Один canvas/foot pivot, согласованные прозрачность, одежда и пропорции для всех кадров. Дискретная смена frame index + допустимое **жёсткое перемещение всего готового спрайта целиком** по пространственной траектории. Во время проигрывания персонажа НЕ масштабировать, не поворачивать, не перерисовывать и не сдвигать отдельные части тела. Для 4/8 ракурсов обязателен собственный утверждённый спрайт каждого вида.
4. Сегментация/rembg исходного эскиза создаёт лишь черновой cutout, **не** ракурс и **не** action-frame. RIFE разрешён только для фоновых/сценических эффектов без персонажей; RIFE не должен генерировать лицо, тело, шерсть, движение хвоста, походку или бой.
5. Каждый NPC имеет **собственный** action timeline, конечный автомат, паузы, реальные реакции и маршруты. Герой контролируется только вводом, NPC живут автономно. Не синхронизировать всех персонажей и не циклировать одну общую анимацию.
6. Отдельные спрайты и сцены сохранять в ZIP. GIF 9:16, цель 40–60 s и 16–24 fps, петля без обрыва, без порчи палитры. Фон дома/неподвижная геометрия должна оставаться привязанной к исходному эскизу.

## Блокирующие условия

- Если у видимого персонажа нет отличающихся полнотелых кадров требуемых действий, его движение **BLOCKED**, а не «приблизительная анимация» или жест с деформацией. Если кадры художественно не подтверждены, обозначить результат `PREVIEW — НЕ УТВЕРЖДЕНО`, а не PASS.
- Перед выпуском запустить `../hero-animator/scripts/character_frame_gate.py MANIFEST.json --renderer RENDER_SCRIPT.py [--preview]`. Для финального утверждённого результата `--preview` не применять. Проверить реальное движение в GIF и число уникальных исходных PNG каждого действия. Нельзя выдавать ложный PASS.
- Не удалять существующие инструменты rembg, RIFE, MaxRects, Rapier, glTF-Transform и PostFX. Запрет **применяется только к персонажной анимации**, окружение остаётся независимым.

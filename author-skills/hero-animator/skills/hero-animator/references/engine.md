# Подключение к своей игре

Перенеси папку с `<id>.json`, листами WebP и необязательным портретом в свои ресурсы. JSON и пути листов должны оставаться рядом. Формат описан в [sprites.md](sprites.md). Игровой код автоматически не изменяется.

Для кадра `[sx,sy,w,h,ox,oy]` вырежи прямоугольник из листа. Точка героя `(x,y)` - его ступни. Рисуй в `(x+ox/ppu,y+oy/ppu)` с размером `(w/ppu,h/ppu)`. У анимации может быть свой `ppu`, он важнее общего. Направление влево можно получить зеркальным преобразованием относительно точки ступней.

Следующий пример предназначен для страницы своей игры, где уже есть `<canvas id="hero" width="800" height="600"></canvas>`. Вставь код в `<script type="module">`, чтобы работал `await` в начале. Пути к своим ресурсам подставь сам. Браузер обычно читает такие ресурсы через сервер игры; для просмотра локальной папки без сервера есть готовый `viewer.html` с выбором файлов.

```js
const canvas = document.getElementById('hero');
const ctx = canvas.getContext('2d');
const base = './assets/mage/';
const meta = await fetch(base + 'mage.json').then(r => r.json());
const images = {};
await Promise.all(Object.values(meta.anims).map(async a => {
  if (images[a.sheet]) return;
  const image = new Image();
  image.src = base + a.sheet;
  await image.decode();
  images[a.sheet] = image;
}));
let anim = meta.anims.idle;
let started = performance.now();
function play(name) {
  anim = meta.anims[name];
  started = performance.now();
}
function tick(now) {
  const n = anim.frames.length;
  let i = Math.floor((now - started) * anim.fps / 1000);
  if (i >= n) {
    if (anim.loop) i %= n;
    else if (anim.loopFrom != null) {
      i = anim.loopFrom + (i - n) % (n - anim.loopFrom);
    } else i = n - 1;
  }
  const [sx, sy, w, h, ox, oy] = anim.frames[i];
  const ppu = anim.ppu ?? meta.ppu;
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.drawImage(images[anim.sheet], sx, sy, w, h, 400 + ox / ppu, 520 + oy / ppu, w / ppu, h / ppu);
  requestAnimationFrame(tick);
}
requestAnimationFrame(tick);
```

Это минимальное проигрывание без смешивания. Нециклическая анимация здесь остаётся на последнем кадре; у себя по завершении переключай её на нужную стойку, а для `hold` сохраняй конец. `pingpong` уже развёрнут сборщиком, дополнительно отражать порядок кадров не надо.

`release` - время события в секундах. Вызывай выпуск при пересечении этого времени, один раз за запуск, а не по равенству дробных чисел. `muzzle` уже в единицах игры относительно ступней, не дели его на `ppu` повторно. При зеркале меняется знак его x. Для больших шагов времени учитывай пересечение границы события, чтобы не пропустить удар.

Для смешивания используй `blend[i]` из JSON. Формула в sprites.md, рабочая реализация - в `viewer/viewer.html`. Не применяй сглаживание к атаке и ульте по умолчанию. Статичный снаряд из листа не заменяет снаряд, который движется по правилам игры.

## Подсказки для движков

| Движок | Как перенести формат |
|---|---|
| Phaser | Зарегистрируй каждый уникальный прямоугольник как кадр текстуры, последовательность собери по `frames` и `fps`. Учитывай разные `ox,oy` для обрезанных кадров; обычная сетка равных ячеек не подходит. Вступление и повтор с `loopFrom` обработай отдельно |
| Godot | Используй прямоугольники через AtlasTexture или собственную отрисовку области текстуры, позицию каждого кадра считай относительно ступней. Частоту бери из JSON, `loopFrom`, `hold` и выпуск обработай в управляющем коде |
| Unity | Если используемая версия не читает WebP, переведи листы в PNG с альфой и обнови имена в JSON. Прямоугольники и точка привязки задаются для каждого кадра. Проверь направление оси y: JSON считает сверху вниз |

Это направления для адаптации, готовые плагины для этих движков не включены. Совместимость проверь в своём проекте.

## Обычный и HD

Два набора должны иметь одинаковые временные последовательности. Переключай только картинки и `ppu`, сохраняя номер кадра. HD полезен, когда герой крупно показан; обычный набор легче для небольшого изображения. Простое правило: рисуй HD, если обычный лист на экране растянут больше чем в 1,15 раза, а на телефоне всегда обычный. Прогрузи нужные листы до первого показа, чтобы декодирование большой картинки не задержало удар. Конкретный выбор разрешения и ограничения памяти зависят от своей игры.

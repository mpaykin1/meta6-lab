# HD по желанию

Сначала человек выбирает концепт и одобряет ролик. Обычный набор можно собрать прямо из 720p. HD - отдельный необязательный этап, он требует NVIDIA, доступной CUDA, torch с CUDA и spandrel. Без них скрипт выдаёт короткую ошибку.

`upscale.py` использует **локальный** файл `RealESRGAN_x4plus_anime_6B.pth`. Его источник: релиз **v0.2.2.4** репозитория **xinntao/Real-ESRGAN** на GitHub: `https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.2.4`. Найди файл в материалах этого релиза и сохрани самостоятельно. Скрипт ничего не скачивает и не обращается к сети.

Дополнительные пакеты, отдельно от обычной сборки:

```sh
python -m pip install torch spandrel
```

Подходящую команду установки torch с CUDA для своей системы проверьте сами. Обычная установка torch может дать сборку без CUDA. Проверка: `python -c "import torch; print(torch.cuda.is_available())"`.

Если у вас стоит ComfyUI portable, ставить ничего не нужно: в его встроенном Python уже есть torch с CUDA и spandrel. Запускайте `upscale.py` им, например `ComfyUI_windows_portable/python_embeded/python.exe scripts/upscale.py ...`. Модель `RealESRGAN_x4plus_anime_6B.pth` у многих уже лежит в `ComfyUI/models/upscale_models/`.

```sh
python scripts/upscale.py mage/clips/attack.mp4 mage/hd/attack.mp4 --model models/RealESRGAN_x4plus_anime_6B.pth --work mage/upscale_work
```

Модель увеличивает кадр x4, затем результат уменьшается до x2. Частота и число кадров сохраняются, звук не переносится. Обработка идёт плитками с перекрытием; `--tile` уменьшает размер плитки при нехватке видеопамяти. Временные кадры создаются только под заданным `--work` и удаляются после обработки. Проверь итог: модель может изменить тонкие детали, а не только резкость.

Для ориентира: на RTX 5070 секунда клипа 720p обрабатывается около минуты, весь набор героя займёт около часа, поэтому HD удобно запускать на ночь. Повтори для всех одобренных клипов. Не считай готовым файл, который ещё записывается: дождись успешного завершения, проверь ffprobe и кадры.

## Пересчёт конфига

Сохрани отдельный конфиг и отдельный `out_dir`. Для исходных координат в видео x2:

- `src_height`, `foot`, `offset`, заданный числом `muzzle`, первые четыре числа каждой маски, `portrait.box` и ширину полосы `groundHaze` умножь на 2.
- В `erase` радиусы `ring` умножь на 2, `area` и `minArea` на 4. Доли, углы, яркость и насыщенность не меняются.
- `video` направь на увеличенные клипы. `warp`, fps, `release`, `loopFrom` и моменты времени масок не меняются.
- `height`, `shadow`, размер выходного портрета и игровые координаты не меняются.

Можно собрать два полных набора из увеличенных клипов: обычный с прежним `ppu`, HD с `ppu` x2. У анимаций со своим `ppu` его тоже нужно удвоить. В обоих наборах должны совпасть анимации, fps, число кадров и моменты событий.

Масштаб x2 сам по себе не означает, что герой должен стать в игре вдвое больше. Движок делит размеры и смещения на `ppu`; см. [engine.md](engine.md). Не заменяй исходные клипы, пока не проверил оба набора. Время обработки и размер HD заранее не обещаются.

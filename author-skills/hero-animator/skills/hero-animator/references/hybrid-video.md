# Hybrid video pipeline: лёгкая игра без потери арта

## Когда использовать

Используй этот режим, когда пользователь или автор прямо говорит, что видео обычно легче по весу и это важно для проекта. Это особенно полезно для фоновой атмосферы: туман, искры, огонь, дальние анимированные руины, световые пульсации, лёгкая дымка, looping FX.

## Базовый принцип

- **Atlas / JSON** — для всего, чем нужно управлять как игровым объектом.
- **Video loop (WebM/MP4)** — для длинных неинтерактивных или почти неинтерактивных визуальных циклов.
- **GIF** — только preview/approval.

## Карта решений

### Делай atlas, если элемент:
- должен реагировать на ввод;
- должен менять направление;
- имеет событие удара / выстрела / release;
- нуждается в хитбоксе или коллизии;
- состоит из коротких действий с точным таймингом;
- должен останавливаться на конкретном кадре;
- должен существовать в нескольких состояниях и сочетаться с логикой игры.

### Делай video loop, если элемент:
- декоративный;
- бесконечно цикличный;
- не требует точной покадровой логики;
- выглядит лучше как плавная живая текстура;
- значительно выигрывает по весу относительно длинного покадрового атласа.

## Рекомендуемый pipeline

1. Сделай художественные preview-loop анимации из утверждённого арта.
2. Согласуй движение на GIF или WebM-превью.
3. Для персонажей экспортируй кадры и упакуй их в atlas+JSON.
4. Для атмосферных FX сохрани циклы как WebM.
5. В HTML-сцене загружай оба типа ресурсов: изображения и видео.

## Важные ограничения

- Не маскируй нехватку ассетов утверждением «это просто video mode».
- Не заменяй атмосферным видео основных игровых персонажей, если нужна интерактивность.
- Не выдавай примитивную сцену за «лёгкую». Лёгкая сцена тоже должна оставаться художественно верной исходному эскизу.

## Минимум, который должен проверить исполнитель

- Видео-лупы бесшовные.
- У героя нет прыжков anchor/pivot между кадрами.
- Прозрачность, если нужна, обеспечена для PNG-слоёв; видео не ломает композицию.
- Пользователь понимает, какие слои интерактивные, а какие фоновые.

# Типовые ошибки

| Этап | Что сломалось | Что сделать |
|---|---|---|
| Концепт | Варианты отличаются только цветом | Измени природу существа, тело, лицо, оружие и характер; имя должно читаться во всех |
| Концепт | Слишком реалистично, грязно или много мелочи | Верни чистую мультяшную заливку, крупные формы и стиль своей игры |
| Концепт | Неестественный хват, свободная рука ничего не делает | Исправь до видео; такие детали затем меняются между кадрами |
| Белый фон | Исчезла белая часть героя | Попробуй `--no-holes`, проверь на тёмном фоне. Если белый предмет слился с внешним фоном, исправь картинку |
| Стартовый кадр | Герой или оружие упираются в край | 16:9, около 46% высоты, запас для прыжков и взмахов |
| Flow | Настройки закрывают отправку | Закрой панель обычным Escape, снова прочитай страницу, проверь новую задачу |
| Flow | В клипе другой персонаж | Проверь обе миниатюры стартового кадра перед каждым запросом; слоты сбрасываются |
| Flow | Камера приближает героя | Требование неподвижной камеры и постоянного малого размера поставь первой фразой КАПСОМ |
| Flow | Скачался прежний клип или не всё скачалось | Дождись завершения, сверяй число и кадры; не доверяй имени файла и одному нажатию |
| Клипы | Оружие меняет руку, пропало или появилось лишнее | Покадрово посчитай оружие, уточни руку первым требованием, переделай только плохой клип |
| Клипы | Бросок превратился в рубящий удар | Опиши уход оружия из руки и видимый способ возврата/взятия нового |
| Клипы | При смерти прилетает чужое оружие | Опиши падение от усталости без внешнего удара, либо убери только чужой снаряд маской по времени |
| Клипы | Бытовой жест превратился в шаги вперёд | Явно зафиксируй ступни на месте и проверь их в каждом кадре |
| Клипы | Однокадровая вставка или большой скачок позы | Смотри последовательную крупную сетку, переподбери участок или переделай клип |
| Клипы | Радость взяли из победы | Сними отдельный `idle_happy`, он входит в обязательный набор |
| Сборка | Зелёная или розовая кайма | Проверь RGB фона и `despill`; для пурпурного используй `hue`, а не агрессивный `all` |
| Сборка | Удалился одобренный эффект | Отключи неподходящие маски, `dropBorder`, `keepMain`, `alphaMin` или `groundHaze`; они могут стереть нужное |
| Сборка | Крупный лист из фоновых точек | Найди шум по кадрам, подбери `minArea` или точечные маски, не стирай нужные частицы вслепую |
| Сборка | Сообщение о касании края | Проверь исходный кадр до гашения края. Потерянную часть тела очистка не восстановит |
| Сборка | Размер героя скачет между клипами | Задай свои `src_height` и `foot` у анимации, если камера действительно изменила масштаб - переделай видео |
| Сборка | Парящий герой постоянно дрожит | Отключи `groundClamp`, точку привязки выбери по нижнему кончику и проверь петлю |
| Сборка | Мушка выпуска не на оружии | `muzzle: "auto"` ищет золотую деталь; для другого оружия укажи `[x,y]` вручную |
| Сборка | Петля двигается шагами | Не растягивай кусок медленнее 1:1, оставь 24 fps исходника; не набивай повторные кадры ради 30 |
| Сборка | Двойные руки и тонкие контуры | Посмотри `blend_check`, выключи `blend` у проблемной анимации и пересобери |
| Сборка | После HD появился шум или потерялась маска | Удвой исходные координаты, длины и радиусы, площади умножь на 4; время и fps не меняй |
| Просмотр | JSON выбран, картинок нет | Выбери папку с JSON и всеми листами; относительные имена должны совпадать |
| Движок | Герой стал вдвое больше в HD | Используй свой `ppu` анимации, дели размеры и смещения на него |
| Движок | Победа стартует заново вместо петли после вступления | Выходной `loopFrom` - номер кадра, не секунды |

60 fps, дорисовка промежуточных кадров и разбиение героя на движущиеся куски не исправили исходные проблемы. Основной путь - цельные клипы Omni, правильный выбор времени и проверка каждого кадра. Veo остаётся запасным, а не обязательным дополнительным проходом.

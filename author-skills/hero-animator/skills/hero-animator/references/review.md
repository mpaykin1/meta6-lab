# Проверка клипов до ролика

Составь короткий список постоянных деталей по выбранному концепту: форма головы, одежда, оружие, рука, крупные украшения, цвет. Сверяй с ним каждый клип.

## Четыре проверки

| Проверка | Что искать | Решение |
|---|---|---|
| Артефакты | Срезы по краям, чужое оружие, смаз, пол, кайма, водяной знак, наезд камеры | Участок убрать при подборе времени, маска только вне героя/одобренного эффекта, либо переделать |
| Лишние детали | Второй предмет, новое украшение, лишняя конечность | Маленькое устойчивое пятно можно убрать `erase`; крупное или меняющееся - переделать |
| Пропавшие детали | Исчезнувшее оружие, смена руки, потерянная часть шляпы, изменение цвета | Проверить каждый кадр; короткий негодный участок можно пропустить, иначе переделать |
| Соответствие игре | Стиль, масштаб, читаемость, характер удара, смысл атаки и ульты | Сравнить со своими материалами игры; ульта крупнее и ярче атаки, бросок действительно бросает оружие |

## Смотри движение крупно

Общий лист помогает найти участок, но может пропустить ошибку длиной в один кадр. Для атаки, ульты, урона и смерти смотри подряд каждый кадр в области действия и считай оружие. Проверяй также исходную и конечную позу, рост и расположение ступней между клипами.

```sh
python scripts/clipsheet.py mage/attack_frames.png mage/clips/attack.mp4 --frames 0-80 --crop 0.15,0.2,0.85,1 --all --cols 8 --width 220
```

Номера кадров с нуля, границы `--frames` включены. `--crop` задаётся долями кадра. Без `--all` выбираются равномерные кадры; `--count` задаёт их число. Не подменяй проверку всех кадров выборкой.

```sh
python scripts/motion.py mage/clips/attack.mp4 mage/clips/ult.mp4
```

```sh
python scripts/measure.py mage/clips/idle.mp4 mage/clips/attack.mp4 --time 0
```

Числа движения помогают найти замах и удар. `measure.py` измеряет крупнейшую область по цвету, поэтому это подсказка, а не доказательство одинакового роста при любой позе.

## Решение по клипу

Запиши одну строку: `attack: принять; hit: маска чужого снаряда справа; death: переделан из-за лишнего оружия`. Допустимы принятие, пропуск участка через `warp`, точечная маска, `erase` или новая генерация только этого клипа. Не принимай плохой клип из-за того, что дубль один.

До одобрения реши, какие эффекты подходят. После одобрения нельзя вырезать согласованные звёзды, дуги, дым и пыль. Очистка не должна маскировать потерю ног или оружия.

Собери и открой ролик всех выбранных клипов:

```sh
python scripts/clips_reel.py mage/review.mp4 "Атака=mage/clips/attack.mp4" "Ульта=mage/clips/ult.mp4" "Радость=mage/clips/idle_happy.mp4" "Победа=mage/clips/victory.mp4"
```

Добавь остальные клипы набора в ту же команду. Если выбран только участок, форма аргумента `"Ульта=mage/clips/ult.mp4:0.5-4.2"`. Ролик 960x540, 24 fps, подпись расположена отдельно от изображения и не закрывает его верх.

**Покажи ролик и жди одобрения человека.** До ответа листы и HD не собираются. После сборки повтори проверку лентами `anim_strip.py` и серединами переходов `blend_check.py`.

# Immutable Character Source in every renderer

At game compile time, any potentially conflicting GIF that depicts the player must not be used for idle, walk, run, attack, crouch or jump. `offline_pack.py` invokes `single_hero_guard.lock_manifest`: the single canonical source clip ID, SHA256 and permitted frame indices must be fixed before asset embedding. This is fail-closed. Ambient and portal GIF remain independent. A new visual action requires frames of the **same confirmed character**; importing a visually similar GIF without approval does not unlock that action. Never use a fallback to another character when a frame is missing. The guard keeps physics interactions if the matching action sprite is unavailable but does not synthesize a pose. The guarantee concerns no cross-source character switch; author frame continuity still needs a human visual audit.

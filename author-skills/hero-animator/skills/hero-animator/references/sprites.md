# Листы спрайтов и конфиг

```sh
python scripts/make_config.py mage/clips mage/hero.json --id mage --out-dir sheets --work work
```

Это заготовка, не готовая разметка. Имена `attack`, `ult`, `hit`, `idle`, `idle_happy`, `stun`, `victory`, `death`, `fidget_*` распознаются по файлам; `ult` становится `cast`, хеш в конце имени отбрасывается. При совпадении имён остаётся первый файл по алфавиту; `idle_calm` имеет приоритет над другим `idle`. Консоль сообщает о совпадениях. Выбери правильные клипы сам. `cheer` получает тот же клип победы, но отдельные параметры. Ключ `--float` отключает привязку к земле, `--force` разрешает заменить существующий конфиг.

Подбери время удара по [timings.md](timings.md), замерь рост и ступни, затем:

```sh
python scripts/video2sheet.py mage/hero.json --preview
```

Можно пересобрать часть: `python scripts/video2sheet.py mage/hero.json attack cast --preview`. Частичная сборка сохраняет остальные записи в существующем JSON; полная строит список анимаций из текущего конфига. Удалённые из конфига старые картинки автоматически не удаляются.

Все пути конфига считаются относительно самого JSON, включая `video`, `out_dir` и `work`. Абсолютные пользовательские пути тоже допустимы. `out_dir` и `work` должны различаться. Не помещай кеш внутрь папки листов. Пример структуры: `mage/hero.json`, `mage/clips/*.mp4`, `mage/work/`, `mage/sheets/`.

Выход - по одному **WebP** на анимацию, `<id>.json` и необязательный `portrait.webp`. Ключ `--preview` кладёт `preview_<имя>.png` в `work`. Сборка не требует сети.

## Верхние поля

| Поле | Значение |
|---|---|
| `id` | Имя набора: латинские буквы, цифры, `_`, `-`; становится именем JSON |
| `out_dir` | Папка листов и `<id>.json` |
| `work` | Отдельная папка кеша извлечённых кадров и превью |
| `ppu` | Пиксели листа на единицу размера в игре. Например 1.0; больше - крупнее лист |
| `height` | Желаемый рост героя в единицах своей игры |
| `src_height` | Рост героя в исходном кадре в пикселях; отношение `height/src_height` задаёт масштаб |
| `foot` | `[x,y]`, общая точка между ступнями в пикселях исходника |
| `shadow` | `[ширина,высота]` для описания тени в единицах игры; сборщик не рисует её в лист |
| `key` | RGB `[r,g,b]` или `"auto"`: медиана полос по краям каждого кадра |
| `despill` | Подавление цвета фона в кайме и свечениях: `"all"`, `"hue"` или отсутствие |
| `despillHue` | `[полный_угол,угол_затухания,мин_яркость]`: дополнительное окно оттенка для светлых пикселей, при `despill: "hue"` |
| `minArea` | Удаление мелких отдельных областей альфы, площадь в пикселях исходника; по умолчанию 60 |
| `quality` | Качество WebP, по умолчанию 86, в примере 80 |
| `dropBorder` | Удаление отдельных областей у края, кроме крупнейшей, и плавное гашение у края; в сборщике по умолчанию `true`, в безопасной заготовке `false` |
| `groundClamp` | Поднимать кадр, если низ силуэта ушёл ниже земли; по умолчанию `true`, парящему герою обычно `false` |
| `masks` | Прямоугольники `[x0,y0,x1,y1]` в пикселях видео; ещё `[x0,y0,x1,y1,с,по]` действует только в указанное время исходного видео |
| `erase` | Массив правил точечного стирания по цвету и форме, описание ниже |
| `alphaMin` | Обнулить альфу меньше заданной доли 0..1; по умолчанию 0 |
| `groundHaze` | `[полоса_px,мин_яркость,макс_насыщенность]`: убрать светлое бесцветное в полосе вокруг ступней |
| `anims` | Словарь анимаций, хотя бы одна |
| `portrait` | Необязательный портрет: поля ниже |

Обязательны `id`, `out_dir`, `work`, `ppu`, `height`, `src_height`, `foot`, `shadow`, `anims`. Размеры и fps положительные. `warp` не пустой, его отрезки должны попадать в клип.

## Поля каждой анимации

| Поле | Значение |
|---|---|
| `video` | Путь к клипу |
| `fps` | Частота листа: 30 для ускоренных действий, 24 для петель 1:1 и действий стойки |
| `warp` | Массив `[начало_видео,конец_видео,длительность_результата]`, всё в секундах |
| `src_height`, `foot`, `ppu` | Свои значения вместо общих, если клип снят с другим масштабом или нужно другое разрешение листа |
| `offset` | `[dx,dy]` в пикселях видео; смещение точки привязки, по умолчанию `[0,0]` |
| `release` | Событие выпуска в секундах результата: атака 0.16, ульта 0.32 |
| `muzzle` | `[x,y]` в пикселях видео или `"auto"`; в выходе превращается в координаты относительно ступней в единицах игры |
| `loop` | Зациклить весь результат |
| `pingpong` | `true`: добавить обратную последовательность без удвоения крайних кадров; число: обратный ход только участка с этой секунды результата |
| `loopFrom` | После первого прохода повторять с этой секунды результата; на выходе превращается в номер кадра |
| `hold` | Удерживать последний кадр, например у смерти |
| `label` | Подпись анимации |
| `blend` | Явно включить или выключить смешивание. По умолчанию включено для `idle`, `idle_happy`, `stun`, `victory` |
| `keepMain` | `[[с,по],...]` в секундах видео: оставлять только крупнейшую область, осторожно с отдельными предметами и эффектами |
| `masks`, `erase`, `minArea`, `despillHue`, `alphaMin`, `groundHaze`, `dropBorder`, `groundClamp` | Свои значения вместо общих. Массивы заменяют общие целиком, не дополняют |

У `video`, `fps`, `warp` нет значений по умолчанию. `pingpong` формирует последовательность кадров, сам по себе не включает бесконечное повторение: нужен `loop` либо `loopFrom`. Победа обычно имеет вступление, затем `loopFrom` и `pingpong` с конца вступления. `cheer` идёт целиком один раз от стойки до стойки.

Портрет: `{"anim":"idle","t":0,"box":[x0,y0,x1,y1],"size":256}`. `t` - секунда исходного видео, `box` - пиксели исходника, `size` - сторона квадратного портрета. Он вырезается отдельно из исходного кадра с цветовой очисткой, не из готового листа; проверь выбранную область.

## Цвет, эффекты и стирание

Фон снимается только по цвету. `despill: "all"` подходит, если в герое нет цвета фона. Иначе он может сделать часть героя прозрачной. Для пурпурного фона используй `"hue"`, чтобы не испортить красные и телесные участки. `despillHue`, например `[50,80,0.6]`, помогает очистить светлые дуги, но требует проверки.

**Одобренные эффекты сохраняются.** `keepMain` стирает любое отдельное пятно, в том числе нужные звёзды и лежащее оружие. `alphaMin` может съесть полупрозрачные эффекты, `groundHaze` - белые ноги. Эти параметры не включаются без причины. `dropBorder` не восстанавливает части, уже срезанные исходным видео.

**Водяной знак Omni.** В правом нижнем углу клипа Omni стоит небольшой значок. В 720p его закрывает общая маска `[1120,560,1200,640]`, она уже есть в примере конфига. Если у анимации свои `masks`, добавь эту маску и туда: массив анимации заменяет общий целиком.

Правило `erase`:

```json
{"hue":[28,62],"sat":0.4,"val":0.4,"area":[20,2200],"bg":0.25,"ring":[3,8],"ymax":0.6,"fill":0.55,"aspect":1.7,"protect_hue":[250,300],"xmin":0,"xmax":1}
```

`hue` - диапазон оттенка в градусах, `sat` и `val` - минимальные насыщенность и яркость 0..1, `area` - площадь пятна в пикселях видео. `ring` - внутренний и внешний радиус кольца вокруг пятна, `bg` - минимальная доля фона в нём. `ymax` ограничивает область сверху долей высоты силуэта, `xmin/xmax` - долями ширины слева. `fill` - минимальная заполненность рамки пятна, `aspect` - максимальное отношение его сторон. `protect_hue` защищает выбранный оттенок. После стирания также чистятся тонкие остатки рядом, поэтому открой все затронутые кадры.

При переходе на видео x2 умножь все исходные координаты, длины и радиусы на 2, площади на 4. Секунды, fps, `height` и цвет не меняются. Выходной `ppu` выбирается отдельно: см. [hd.md](hd.md).

## Упаковка и выходной JSON

Кадры плотно обрезаются по альфе с небольшим полем и укладываются в лист шириной до 2048, 4096 или 8192 px. Высота ограничена 8192 px; при превышении уменьши `ppu`. Повторяющиеся кадры и обратный ход ссылаются на те же области листа.

```json
{"id":"mage","ppu":1.0,"height":245,"shadow":{"w":78,"h":13},"anims":{"attack":{"sheet":"attack.webp","fps":30,"frames":[[0,0,120,240,-60,-238]],"release":0.16,"muzzle":[80,-140]}}}
```

Каждый кадр: `[sx,sy,w,h,ox,oy]`. Первые четыре числа - прямоугольник листа в пикселях; последние два - смещение левого верхнего угла относительно ступней, тоже в пикселях листа. Для рисования в единицах игры дели `w,h,ox,oy` на `anims.<имя>.ppu` либо общий `ppu`.

В анимацию копируются `loop`, `hold`, `release`, `label`. `loopFrom` на выходе уже **индекс кадра с нуля**. `muzzle` уже в единицах игры, делить его на `ppu` снова не нужно. Обратный ход уже включён в массив `frames`; отдельного поля `pingpong` на выходе нет. Длительность - `frames.length/fps`.

`blend[i]` - `[доля,dx,dy]` или `[0]`: какую последнюю долю интервала кадра смешивать со следующим, и общий сдвиг силуэта в пикселях листа. Текущий кадр движется к следующему на `u*[dx,dy]`, следующий начинает на `-(1-u)*[dx,dy]`. Вес кадров `1-u` и `u`; цвет складывается с учётом альфы. Последний кадр смешивается с началом петли, если оно есть. Нулевая доля означает обычную смену кадра.

Разметка автоматически строится при сборке. `blendmap.py META --stats` только показывает статистику; без `--stats` обновляет разметку стандартных плавных анимаций и уже размеченных анимаций. Для явного выключения используй `blend: false` в конфиге и пересобери.

```sh
python scripts/anim_strip.py mage/sheets/mage.json mage/strip.png --anims attack,cast --cols 8
```

```sh
python scripts/jerk_check.py mage/sheets/mage.json --anims idle,stun,idle_happy
```

```sh
python scripts/blend_check.py mage/sheets/mage.json mage/blend.png
```

Смотри ленты в полном размере: все кадры относительно ступней, выпуск отмечен рамкой, точка вылета кружком. У `jerk_check` медиана и шов помогают найти подозрительное место, но не определяют качество сами по себе. `blend_check` показывает середины рискованных смешиваний; там не должно быть двойных рук и оружия.

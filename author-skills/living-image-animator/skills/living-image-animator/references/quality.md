# Living-world visual acceptance

**PASS only when** deliverables exist, GIF has >1 visually distinct frame, RGBA layers correspond to visible objects of source, same actor identity is maintained in all pose sprites, all claimed actions have visible local motion rather than frame-regenerated global change, no ghost silhouettes, all background holes are filled, landscape/portrait original framing retained, cycles seamless, actors move at independent non-homogeneous times, lights have distinct timing, day/night includes full sky/background transition and not only brightness.

For requests like 'animate everything', make a scene inventory and ensure every animate-able semantic entity has a local motion plan (or mark in the final response that exact extraction was not possible). Do not call overall scene 100% animated if only 40% of actors have poses. A **character counts as actively animated** only if its own sprite or rig shows at least two semantically distinct poses; scaling/translation-only is micro-motion. A light counts animated only if visibly varies. A leaf/tree counts animated with sway or falling. Sky counts animated with moving sky objects plus light transition. The animated GIF must be opened and checked; a script existing is not equivalent to a rendered result.

# glTF-Transform — 3D optimization extension (module 3)

Pipeline: **Tree-sitter source inspection** → **Assimp GLB2 normalization** → **glTF-Transform conservative optimization** → **Three.js / GLTFLoader**.

- Upstream: https://github.com/donmccurdy/glTF-Transform
- Verified upstream main SHA 2026-11-21: `8e2a94a2616d293c4b503d0fb6a4b42e6ec7c62f`.
- Runtime npm: `@gltf-transform/cli@4.5.1` (Node ≥20), exact version in `optimizer-deps/package.json`.
- License: MIT, bundled as `vendor/gltf-transform/LICENSE.md`.
- **Only license, local adapter, manifests and example loader included**. Complete upstream source, CLI runtime/npm node_modules, native Assimp executable and game models are **not** bundled. This is a runtime integration, not a claim that a full GitHub repository was cloned.

## One shared library

1. Use `fusion.py scan` on authorized game source projects. No writes to original repositories.
2. Run `assimp_bridge.py convert` to populate `model-library.json` and `glb/` (or catalog already-GLB2 assets).
3. If npm access is available, run `npm install --ignore-scripts --prefix skills/meta-game-fusion/optimizer-deps` **once and only when authorized**. The local optimizer is auto-detected; alternatively install `@gltf-transform/cli@4.5.1` in PATH. `sharp` may require additional platform-specific installation; do not force it.
4. Run the optimizer: `python skills/meta-game-fusion/scripts/gltf_optimize.py optimize --models /path/library/model-library.json --profile safe`.
5. Optimized artifacts go in `optimized-glb/` and catalog in `optimized-model-library.json`. Both carry source game, relative model path, source/index hashes, converted GLB hash, optimized hash, approval state and license status.
6. In Three.js use `templates/three-loader.mjs` for GLB2. The loader returns authored clips and does **not** play animations automatically.

## Profiles

- `safe` (default): `gltf-transform dedup`. No geometry quantization, mesh merge, node flattening, animation resample, texture conversion or extension introduction. Reject changed scene graph, skeleton, target tracks, interpolation, materials/nodes/counts. Keep original if result not smaller.
- `meshopt` (explicit): `dedup` then `meshopt --level medium`. Produces `EXT_meshopt_compression` assets that need `GLTFLoader.setMeshoptDecoder()`. This extension is supported in the included Three.js loader, but test playback before use.
- `webp` (explicit): `dedup` then `webp`. Texture transcoding is **lossy** and adds `EXT_texture_webp`. Preview before acceptance; original bitmap assets remain untouched. Do not apply to author-approved pixel art or sprites without explicit approval.

## Safety

No user-provided code execution; CLI invocation uses argument arrays and timeouts. Input files re-hashed against both Tree-sitter catalog and Assimp model registry; existing outputs are verified and never overwritten. Original sources and Assimp GLBs remain intact. Size bounds, symlink protection, strict GLB2 header and JSON checks, animation/skin/node structural gates, pinned CLI version. Store outputs outside source repositories. A valid structurally preserved file still requires visual review and rights verification; `approved_for_reuse=false` is preserved.

**Absence of the CLI**: `inventory` works offline; `optimize` marks records as unavailable and returns nonzero. Do not claim optimization occurred. **No published game** is generated by this module alone.

# Recommended cross-skill paths

1. **Рисованная 2.5D RPG:** Forge (style) → Hero Animator (approved sprites/actions) → Voxel Creator (GLB level) → Blender (only if needed for static meshes/rig) → Atmosphere (FX preset) → Fusion (one player, one physics, one renderer). Casual Studio contributes optional UI and mini-games.
2. **Pixel voxel horror:** Forge → Voxel Creator Vesper/Blockwild → Atmosphere Engine (rain, fog, light) → Blender (safe geometry repair) → Fusion (Rapier/Ink/NPC navigation); Hero Animator only if approved 2D hero is required.
3. **Cute mobile game:** Forge (palettes, optional) → Casual Studio (scene and gameplay) → Voxel Creator (props) → Blender (optional GLB polish) → Hero Animator (approved hero if available) → Atmosphere (optimized touch-friendly mood) → Fusion only for advanced narrative/navmesh/large cross-module projects.
4. **Visual iteration loop:** Fusion / Casual / Voxel screenshots -> Forge reference comparison -> style parameters -> Atmosphere/Blender/Voxel -> regenerate only affected assets; approved hero is never silently replaced.

Cross-skill handoffs are asset and intent exchanges, not cross-plugin procedure calls unless a real connector action is available. If the user asks to actually compose the game, move to an executable project and run/render it. Keep proof and measured compatibility separate from theoretical routes.

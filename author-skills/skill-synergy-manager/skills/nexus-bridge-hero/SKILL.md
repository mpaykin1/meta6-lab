# Skill Nexus — hero-animator

Использовать для межскиловой передачи **существующих** артефактов игры. Этот мост не заменяет родной игровой движок и не утверждает, что модель или анимация была улучшена. Проверка целостности, типобезопасная передача GLB/PNG/JSON и адаптация в сцену выполняются реальным локальным Python-скриптом этого модуля.

Исходный файл должен быть произведён именно родным пайплайном скила. Нельзя создавать искусственную модель, менять утверждённого героя, подменять анимации или выдавать подготовленное описание за запуск внешнего Blender/Rapier/Three.js. Авторские права должны быть подтверждены.

При наличии конкретного source-файла отправить скилу `hero-animator`:

`python skills/nexus-bridge-hero/bridge.py export --to TARGET --asset FILE --out HANDOFF --game GAME --character HERO --rights-owned`

При получении пакета от другого игрового скила:

`python skills/nexus-bridge-hero/bridge.py import --bundle HANDOFF --scene GAME_SCENE.json`

Обновление `GAME_SCENE.json` — рабочая интеграция **сценных данных**; живое использование в оригинальном игровом цикле требует отдельной проверки реального браузерного билда. Не засчитывать этот модуль как готовую интеграцию движков без запуска.

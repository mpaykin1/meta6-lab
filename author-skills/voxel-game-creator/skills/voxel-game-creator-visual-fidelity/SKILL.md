# VISUAL FIDELITY — HARD STOP BEFORE GAME RELEASE

This skill is compulsory with every playable game generated by Voxel Game Creator (also with animated-world-guard). It directly prevents the mistake observed in the November 21, 2026 Forest of Lanterns preview: large blank sky + tiny sliced objects in place of full voxel source-engine scenery.

## Non-negotiable

1. **USE THE ACTUAL ENGINE SOURCE**, not a handmade `getContext('webgl2')` cube-grid engine called “Voxelize”, “Lumenwild”, “Ragnagrok” or “Luanti”. Use pinned source checkout, preserve the original terrain meshing, materials, renderer, atmosphere, lighting, water, trees, animation and collisions. Lumenwild/Three.js is not a synonym for newly written WebGL shader code.
2. Any game requested “like the original project” **must be visually grounded in an original, actually built source engine**, not just screenshots, engine names, markdown recipes, or a skill manifest. If offline extraction/bundle is unsupported or source is inaccessible, do not fake fidelity. Output may be a clearly described **diagnostic preview**, never a passed game or the original source's graphics.
3. If a single offline HTML is demanded: build a REAL source-engine bundle and inline all compiled modules, GLSL and licensed assets. Browser must run from `file://` with **zero** CDN, `fetch`, module-loader, worker, remote fonts, or external dependencies. Single source HTML where Three.js is linked from CDN is not autonomous.
4. **Preflight real browser render**: 390×844 portrait and 844×390 landscape, after start and after 3+ seconds. Confirm terrain occupies viewport, foliage/houses/creatures appear, user controls move same hero, ambient animations are continuously visible and no WebGL errors or blank/sliced triangle occur. If browser GPU is disabled or screenshots could not be observed, gate returns BLOCK, no visual PASS.
5. **Shader invariant:** fullscreen triangle with `gl_VertexID` has clip coordinates `(-1,-1), (3,-1), (-1,3)` or other fully covering shape. For `p` in `{0,2}`, use `gl_Position=vec4(p*2.-1.,0.,1.)`, `uv=p`; not `gl_Position=vec4(p-1.,0.,1.)` with uv=p*.5. This exact bug was responsible for the half-frame scene. Do not rely on GLSL compilation alone — coverage must be checked via visible frames.
6. **Original artistic fidelity** is not guaranteed by shader correctness. Require visible and recognisable trees, caves, water, terrain textures, depth, ambient lighting and distinctive original style. A prettier primitive demo is not enough.
7. Native source-control/attribution, licensing and pinned SHA must be retained, including separate GPL components such as Veloren and Mineclonia. The hero is one unchanged character; actions only by input; NPC animation is independent. Preserve all existing skills and engines.

## Programmatic gate

After building, invoke `python3 skills/voxel-game-creator/scripts/source_fidelity_guard.py --engine lumenwild --html /path/to/index.html --source-root /path/to/pinned/source --offline --portrait /path/to/portrait.png --landscape /path/to/landscape.png --capture-verification /path/to/browser-proof.json` before announcing game is finished. Browser proof is an internal release gate, **not** a user-facing report.

The gate fails CLOSED if code is synthetic, the source SHA cannot be verified, a known broken fullscreen-triangle shader appears, offline HTML depends on external files, portrait/landscape frames are missing, or runtime proof flags are untrue. A `--preview` run bypasses only source+browser confirmation and explicitly prints **NATIVE ENGINE NOT VERIFIED**; it may not be described as a final source-engine game.

Do not promise actual screenshots, gameplay, performance, or downloads unless produced, and do not invent a hosted URL.

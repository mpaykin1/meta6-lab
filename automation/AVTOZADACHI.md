# AVTOZADACHI — общая инструкция для 5 автозадач (саморазвивающаяся)

Ты автозадача N из 5. Вы работаете по очереди каждый час с шагом 12 минут. Репозиторий: https://github.com/mpaykin1/meta6-lab. Правила: https://github.com/mpaykin1/meta6/blob/main/AGENTS.md

## Шаг 1. Надзор (не больше четверти времени запуска)
Открой журнал automation/NADZOR.md (если его нет — создай). Проверь запись предыдущей автозадачи (для N=1 предыдущая — 5):
- была ли запись за последний час;
- у каждого «сделано» есть доказательство — ссылка на PR, SHA коммита или запуск Actions — и оно открывается и подтверждает сказанное;
- работа была полезной: изменились код, игра, бот или таблица, а не только текст отчёта.
Если запуска не было, доказательство не подтверждается или работа пустая — запиши «ПРОВАЛ: автозадача X, причина», сам доделай её незаконченный шаг и только потом иди дальше. Если одна автозадача проваливается 3 раза подряд — дай ей в журнале одну маленькую конкретную подзадачу на следующий запуск.


**Не путай квоту PR:** лимит 5 относится только к открытым PR с `draft=false`; черновики не считаются. Прежде чем объявить квоту блокером, проверь `draft` каждого открытого PR по свежему API. Отсутствие карточек DISPETCHER не блокирует разбор существующих PR из Z01. Запись только в журнале не считается полезной работой: нужен подтверждённый результат в коде, игре, боте или рабочей таблице.

## Шаг 2. Полезная работа
Возьми самую важную незаконченную группу (важность сверху вниз), начиная с отметки «следующий шаг» в журнале:
1) Z01, Z02, Z03 — завалы PR, честная таблица, эталоны
2) Z04, Z05, Z06 — бот B2–B4 (движение, застревание, смерть)
3) Z07, Z08, Z09 — бот B5–B7 (проход, правила, запуск на PR)
4) Z10, Z11, Z12, Z13 — библиотека L1–L4
5) Z14, Z15 — M6 и этап 2 (Z15 только после финиша 18 из 18)
6) Z16 — улучшить игры
7) Z17 — ассет-паки
Файлы задач: https://github.com/mpaykin1/meta6-lab/tree/main/automation/zadachi — следуй полному тексту задачи.
Не бери подзадачу, которая по журналу сейчас «в работе» у другой автозадачи или у ручного чата. Если всё в группе упирается в то, что может только Claude, — запиши это в журнал и бери следующую группу. Запуск никогда не кончается «делать нечего»: если всё сделано — улучшай игры (Z16).

## Шаг 3. Поддержка других задач и промптов
- Заметил работу для другой задачи — оставь отметку в начале её файла в automation/zadachi (раздел «Начни с этого»), чтобы чат или автозадача с той задачей начали с неё.
- Если по журналу видно, что на какой-то задаче чаты буксуют (повторные провалы, одни и те же вопросы, пустые запуски) — перепиши этот файл задачи понятнее: короче шаги, точнее критерий «готово», конкретнее следующий шаг.
- Если GPT.md (общая ссылка для ручных чатов) устарел — обнови порядок важности по реальному состоянию.

## Шаг 4. Саморазвитие (каждый запуск, одно улучшение)
По журналу найди главное, что мешало (провалы, зависания, пустые запуски, повторяющиеся ошибки), и сделай ОДНО улучшение: в этом файле, в файле задачи или в GPT.md.
- Перед правкой этого файла сохрани текущую версию в automation/versions/AVTOZADACHI_vНОМЕР.md.
- Правь только добавлением и уточнением. Раздел «Неприкосновенно» удалять и ослаблять запрещено.
- В журнал запиши: что изменил, почему (какой провал это лечит), ссылку на коммит.
- Если после изменения 2 запуска подряд стали хуже (больше провалов, меньше полезных изменений) — откати на прошлую версию и запиши это в журнал.

## Шаг 5. Сохранение
После каждого шага коммить и пиши в журнал, чтобы прерванный запуск не терял работу. В конце запуска добавь запись: время, номер N, что сделано с доказательствами, что улучшено (шаг 4), «следующий шаг» для следующей автозадачи. Обнови таблицу «сделано / в работе / зависло».

## Неприкосновенно (нельзя удалять и ослаблять)
- Нашёл ошибку — исправь её сам и только потом сообщай. Отчёт «нашёл ошибку» без исправления запрещён.
- Каждое «сделано», «смёрджено», «проверки прошли» — со ссылкой на PR, SHA коммита или запуск Actions. Без доказательства не считается.
- Не ломай рабочее: новое — только слоем поверх старого; после изменения бот-тестер проходит старое и новое, 0 ошибок; каждая версия хранится отдельным файлом.
- Если запуск прервался — следующий читает журнал, продолжает с места остановки, сделанное пропускает.
- Запуск никогда не кончается «делать нечего».
- Перед отчётом сам сделай всё, что можешь, из своего списка «осталось».
- В отчёте пиши только то, что осталось сделать.
- Ничего платного: только бесплатные средства.

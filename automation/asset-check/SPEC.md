# АССЕТ-ПАК ДЛЯ ИГР МГ / МГЛ — универсальная спецификация и бот-проверщик

Совместимость кодов v1: отсутствие манифеста остаётся A1, прав/происхождения — A6,
content_flags — A7, включая новые виды паков. Упоминания C1/C2 и I1 ниже описывают
группы проверок; машинные ID A1/A6/A7 сохранены, чтобы прежние клиенты и тесты работали.

Бот: `automation/asset-check/check_pack.py` (v2) · ловушки: `test_*.py` · мутанты: `mutate_bot.py` · CI: `.github/workflows/asset-check.yml`
Запуск: `python -I automation/asset-check/check_pack.py <папка|zip> --out <папка_отчёта>`
Владелец 11.11.2026: бот проверяет **любые** ассеты, которые делает ChatGPT; промпт многоразовый, саморазвивающийся, универсальный (`automation/prompts/ASSET_PACK_BOT.md`).

## Виды паков (бот определяет сам; один пак может быть смешанным)
| вид | как узнаёт | файл | проверки |
|---|---|---|---|
| sprite2d | `atlas.json` с `assets` | kinds/sprite2d.py | A, P, G, L (ниже, §2) |
| skin | `skin.json` (meta6-skin/1) | kinds/skin.py | KS1–KS12 = SKINY.md S1–S12 |
| abyss | `manifest.json` со `sprites` | kinds/abyss.py | AB:* — **переиспользует** automation/asset-quality/validate.py |
| model3d | `.glb` / `.gltf` | kinds/model3d.py | M1 читается, M2 меши, M3 треугольники ≤ 20k (HARD > 100k), M4 текстуры ≤ 2048 и степень двойки, M5 масштаб в метрах, M6 скелет с анимациями, M7 ≤ 8 материалов, M8 размер файла, M9 нормали, M10 низ на y=0, M11 есть idle |
| audio | `.wav .ogg .mp3 .m4a .flac .opus` | kinds/audio.py | S1 читается, S2 перегруз, S3 тихо, S4 резкие высокие (правило ЗВУК), S5 тишина в начале, S6 громкость/вес, S7 стык петли, S8 короткая музыка, S9 DC |
| images | картинки без манифеста (запасной) | kinds/images.py | I1 нужен манифест, I2–I4 |
| (нет) | ничего не подошло | — | **U1 HARD: добавь новый вид** |

Общие для всех: **C1** license+provenance, **C2** content_flags (реальные люди/бренды → версия -fiction), **C3** симлинки/пути вне пака, **C4** вес пака, **C5** число картинок, **C6** файлы, которые не проверил ни один вид.
Поля C1/C2 можно писать в любой манифест пака (`pack.json`, `atlas.json`, `manifest.json`, `skin.json`).

### Как бот растёт до любых ассетов
Новый вид (шрифты, шейдеры, видео, воксели .vox, Lottie, частицы…) = файл `kinds/<вид>.py`:
`NAME`, `ORDER`, `detect(root) -> bool`, `check(root, report) -> set(проверенных файлов)`; `report.add(id, "HARD"|"SOFT", где, что не так, как исправить)`.
Плюс ловушки в `test_kinds.py` (чистый образец проходит, каждая подложенная ошибка ловится) и строки в `MUTANTS` в `mutate_bot.py`. Бот подхватит вид сам — правка ядра не нужна.
Если для вида уже есть валидатор в репозитории — вызывать его (как abyss), не переписывать (REUSE).

## 0. Где лежат паки
- `asset-packs/incoming/<имя>/` — пак в работе. HARD-ошибки не валят CI, но пак нельзя брать в игру.
- `asset-packs/ready/<имя>/` — пак готов: **0 HARD**. Переносить сюда только с зелёным прогоном `ASSET CHECK`.
- В каждом паке: `_check/REPORT.md` и `_check/report.json` — последний отчёт бота; `PROGRESS.md` — что сделано по паку (для повтора после зависания).
- Исходный ZIP владельца/ChatGPT не перезаписывать: исправления — новыми коммитами, версия в `atlas.json → version` растёт.

## 1. Манифест `atlas.json` (формат `MG.AssetPack/1`, совместим с `MLGA.PixelAtlas.v1`)
Обязательные поля: `format`, `version`, `tile_size`, `default_filter`, `palette`, `assets`, `animations`, `locales`,
`license` (`type`, `author`, `commercial`), `provenance` (`tool`, `date`, `prompt_sha256`),
`content_flags` (`real_persons`, `brands`, `political`), `hitboxes` (персонаж → прямоугольник тела в кадре).
У каждого ассета: `file`, `type`, `sheet_size` (= реальный размер), `frame_size`, `count`, `loop`, `frames[]` (`x,y,w,h,duration_ms,anchor`).
У `attack`/`shoot`: `events: [{frame, type: hit|spawn_projectile, x, y}]` — кадр, где наносится урон.
У тайлов: `tags.collision`, `tags.seamless` (бесшовный во все стороны), `tags.seamless_x` (кладётся рядом по X).

## 2. Вид sprite2d — что проверяет бот (HARD = пак не годится в игру)
| id | что | уровень |
|---|---|---|
| A1 | манифест есть и читается, обязательные поля | HARD |
| A2 | все файлы из манифеста существуют; лишних нет | HARD / SOFT |
| A3 | sheet_size = реальный размер, кадры по сетке и внутри листа, count = кадрам | HARD |
| A4 | якорь внутри кадра | HARD |
| A5 | duration_ms > 0 | HARD |
| A8 | одинаковые файлы (один тайл на все миры = нарушение БЕЗ ПОВТОРОВ) | SOFT |
| A9 | defeat/attack/damage/jump не должны быть loop=true | SOFT |
| P1 | спрайты с альфой | HARD |
| P2 | полупрозрачные пиксели в пиксель-арте (ореол) | SOFT |
| P3 | пустые кадры | HARD |
| P4 | все кадры одинаковые / повторы соседних кадров | HARD / SOFT |
| P5 | **«мёртвая» анимация**: после совмещения сдвигом меняется < 6 % пикселей (тело стоит, только прыгает или мигает искра) | HARD |
| P6 | спрайт упирается в край кадра (обрезан) | SOFT |
| P7 | цвета далеко от палитры пака | SOFT |
| P8 | ноги прыгают по высоте в idle/run (дрожание) | SOFT |
| P9 | мало кадров (idle ≥ 4, run ≥ 6, attack ≥ 4, defeat ≥ 4) | SOFT |
| G1 | у героя/врага/босса есть все состояния (idle, движение, атака, урон, поражение; у героя ещё jump, fall) | HARD |
| G2 | тайлы с пометкой бесшовности реально бесшовны; ground_top/platform_center без шва по X | HARD |
| G3 | тайл = tile_size, у тайла есть collision | HARD |
| G4 | фон с wrap_x бесшовный по X; mid/near с прозрачностью | HARD |
| G5 | базовый набор тайлов в каждом мире; есть углы/склоны (уровни не прямоугольные) | HARD / SOFT |
| G6 | герой ≥ 32 px | SOFT |
| G7 | все состояния персонажа — один frame_size и один якорь (без скачка при смене анимации) | HARD |
| G8 | preview.png | SOFT |
| G9 | hitbox у персонажа; событие удара у attack/shoot | HARD |
| L1–L3 | локали есть, одинаковые ключи, нет пустых, есть названия миров | HARD |

Чего бот **не** умеет (смотрит человек/Claude): красота, сходство с эскизом, читаемость силуэта на телефоне, смешно ли.

## 3. Саморазвитие бота (обязательно при каждом запуске промпта)
1. Нашёл в паке ошибку, которую бот пропустил → новая проверка в нужном `kinds/<вид>.py` (или ядре) + ловушка в `test_*.py` (синтетический пак с этой ошибкой) + строка в `OSHIBKI.md`.
2. Новый вид ассетов, который бот не знает (U1 или C6) → новый `kinds/<вид>.py` по шаблону выше.
3. Мутации: строка в `MUTANTS` (`mutate_bot.py`); `python automation/asset-check/mutate_bot.py` — все мутанты пойманы.
4. Ложное срабатывание на хорошем ассете → поправь порог, добавь ловушку «хороший ассет проходит».
5. Нельзя: ослаблять или удалять существующие проверки и ловушки, понижать HARD до SOFT без решения Claude/владельца.
6. В `automation/asset-check/RAZVITIE.md` — одна строка на запуск: дата, версия бота, что добавлено, ссылка на прогон.

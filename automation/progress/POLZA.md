## Уроки
- При конфликте двух автоматически сгенерированных `shared/library/index.json` не переносить целиком файл из старой ветки: сравнивать исходные манифесты, обновлять от свежего main и заново запускать индексатор. Не терять новые игры.
- Если два уже проверенных шумных workflow исправлены в одном ожидающем PR (#289), не создавать дубликат. Завершай существующий PR и делай контрольный замер после слияния.
- Исправляй причину одинакового начального layoutHash: меняй расположение настоящей геометрии уровня, а не добавляй фиктивный nonce в наблюдаемое состояние.
- На software WebGL GPU сначала снижай физическое разрешение render target адаптивно; не ослабляй лимиты FINISH, FPS и время прохождения.
- Для статичного лучника нельзя считать движение камеры перемещением героя.
- Из PR #200 переносить только одну игру и сохранять исходный движок точно, без изменения геймплея.
- Делай отложенное объявление __META_BOT__ после инициализации настоящего модуля, а не объявляй API до появления игрового состояния.
- При проверке snapshot-объектов используй глубокое сравнение, а не ссылочное равенство между независимыми вызовами.

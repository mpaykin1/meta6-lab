# stackgen — ассеты спрайт-стакинга без скилов

Автозадачам ChatGPT недоступны авторские скилы и запуск кода. Поэтому ассет делается так:

1. Автозадача пишет **только текст** — `asset-packs/incoming/stack-<полоса>-<id>/recipe.json` (формат — в начале `stackgen.py`, пример — `example/stack-A-lighthouse/recipe.json`).
2. GitHub Actions (`stackgen.yml`, бесплатно) сам рисует настоящие RGBA-срезы `stacks/*.png`, пишет `stack.json` (mg-spritestack/1), превью 8 углов `_check/preview.png` и отчёт `_check/REPORT.md`, коммитит всё обратно в ветку.
3. HARD > 0 → прогон красный. Автозадача читает REPORT.md, правит recipe.json, пушит снова.
4. Зелёный → обычный ASSET CHECK и вставка в игру (роль E).

Проверки (HARD): срезов меньше нормы роли; пустые срезы; соседние срезы одинаковые (плоско); низ = верх; меньше 3 цветов; ассет слишком мелкий; у находки нет `benefit`.

База игры — актуальная версия «Небесного пилота» от 24.11.2026: `reference/nebesny-pilot-v2026-11-24/` (35 файлов, sha256 index.html `ffe4cdda…40c8f`). Старая копия в PR #436 (258 строк, только кольца) — устаревшая.

## Зачем
Система «что сделано / в работе / зависло» уже есть (ZADACHI watch, ZANYATO watch, DISPETCHER, TOLKNUT, STATUS.md), но местами врёт: в `automation/status.json` все пункты финиша «не подтверждено — GitHub недоступен» со старыми ссылками; в DISPETCHER бывает «undefined»; прогоны на main часто `cancelled`. Если сводка врёт, все промпты выбирают не ту задачу.

## Готово, когда
Три запуска подряд: STATUS.md и status.json показывают те же статусы пунктов финиша, что FINISH.md; нет «undefined» / «нет данных» там, где GitHub данные даёт; сторожа на main не отменяются (`cancelled`) друг другом.

## Зачем
Чтобы ни один запуск не кончался «делать нечего», а игры становились лучше, пока пункты финиша ждут Claude.

## Готово, когда
Никогда — это постоянная работа. Один запуск = одна игра = одно улучшение, видимое игроку, с доказательством (ссылка 200 + снимок/число до и после).

## Шаги
1. Выбери игру с самым старым улучшением (`reports/igry/PROGRESS.md`).
2. Прогони по [RULES_CHECKLIST.md](../../rules/09-platforma/RULES_CHECKLIST.md) и по `docs/PLAYGAMA_RETENTION.md` (R1–R10). Возьми одно невыполненное правило.
3. Сделай слоем поверх рабочего кода (НЕ ЛОМАТЬ РАБОЧЕЕ), старая версия остаётся отдельным файлом. Новое — только из ассетов, уже есть в игре. Без рекламы в МГ/МГЛ.
4. Бот проходит старое и новое (B1, и B2–B5 где готовы) — 0 ошибок.
5. Сыграй глазами: стало лучше? Если нет — откати.

## Саморазвитие (после основной работы, обязательно одно)
Сделай улучшение, сделанное в одной игре, универсальным правилом и допиши его в PLAYGAMA_RETENTION через PR `НУЖЕН CLAUDE` (это МГ).

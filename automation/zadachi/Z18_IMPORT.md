# Z18 — СКАЧАТЬ ПОЛЕЗНОЕ ОТКРЫТОЕ (Patch и другие похожие проекты)

> **Многоразовая карточка задачи для обычного чата ChatGPT.** Владелец присылает только ссылку на неё: https://github.com/mpaykin1/meta6-lab/blob/main/automation/zadachi/Z18_IMPORT.md
> **Порядок:** 1) открой [GPT.md](https://github.com/mpaykin1/meta6-lab/blob/main/GPT.md) и выполни разделы 0–2 (кто ты, правила, ПУЛЬС — толкни/почини то, что сломано по пути); 2) прочитай `reports/patch-import/PROGRESS.md` и продолжи с «что дальше» (нет файла — создай); 3) выполни эту карточку; 4) цель карточки достигнута или упёрлась в «НУЖЕН CLAUDE» — не останавливайся, бери следующую задачу по разделу 3 GPT.md; 5) в конце — разделы 5–6 GPT.md (развитие и короткий ответ).
> Эту же ссылку можно присылать снова без изменений — работа продолжится с места остановки.

## Зачем
В интернете есть проекты, похожие на МГ/МГЛ (первый — [Patch](https://github.com/patch-gg)). Всё открытое и полезное оттуда (эффекты, анимация, инструменты, боты) переносим к себе, чтобы игры стали лучше, а мы не писали заново то, что уже есть.

## Готово, когда
Никогда — это постоянная работа. Один запуск = один компонент доведён до конца: оригинальные байты с закреплённого коммита, лицензия и NOTICE рядом, запись в `integration/<источник>/REGISTRY.json`, компонент в `shared/index.json`, работает в демо или игре (ссылка 200), бот/проверки зелёные.

## Подробный порядок
Для Patch — полностью по [automation/prompts/PATCH_IMPORT_SELF_EVOLVING.md](../prompts/PATCH_IMPORT_SELF_EVOLVING.md). Для любого другого источника — тот же порядок, папка `integration/<источник>/`. Коротко:
1. **Сначала доведи начатое.** Сейчас это [#310 PixelFX](https://github.com/mpaykin1/meta6-lab/pull/310): конфликт с main и 44 файла. Влей main, разбей на 2–3 PR (исходники MIT + LICENSE/NOTICE + реестр → адаптер + индекс → демо). Правки `.github/workflows/` — отдельным маленьким PR `НУЖЕН CLAUDE`.
2. **Права — до скачивания.** Для каждого файла: URL, commit SHA, blob SHA, автор, лицензия из того же коммита. Решение ALLOW / REVIEW / BLOCK в REGISTRY.json. Берём только то, что разрешает изменять, распространять и использовать коммерчески (MIT, Apache-2.0, BSD, CC0, CC-BY с атрибуцией). Код под MIT не значит, что модели, веса, шрифты, логотипы и картинки тоже свободны — их проверяй отдельно. Нет доказательства — BLOCK, не выдумывать.
3. **Байты как есть.** Неизменённые исходники отдельно от нашего адаптера. Проверка совпадения: `git hash-object` скачанного файла = blob SHA из реестра (ловушка: изменить 1 байт → проверка краснеет).
4. **Только бесплатно**: без платных API, ключей, закрытых весов, CDN во время игры, тяжёлого GPU/CUDA.
5. **Польза видна в игре**: подключи через библиотеку в демо или в игру, по правилам AGENTS.md МГ (ЧИСТЫЙ ЭКРАН, ЗВУК, ВИДИМО И ЭКОНОМНО, НЕ ЛОМАТЬ РАБОЧЕЕ). До/после в браузере, ПК и телефон, 0 ошибок консоли.
6. **Новые источники**: нашёл ещё один похожий открытый проект — добавь его строкой в `integration/SOURCES.md` (имя, ссылка, лицензия, что полезного) со статусом REVIEW. Импорт — только после проверки прав.

## Саморазвитие (после основной работы, обязательно одно)
Проверь, что нового появилось в уже известных источниках (новые коммиты, репозитории), и добавь в очередь; или усиль проверку прав/байтов новой ловушкой.

## Правила
Полностью по [rules/09-platforma/SEO_KATALOG.md](../../rules/09-platforma/SEO_KATALOG.md). **Раздел 0 (поправки Claude) главнее остального**: SEO-текст не на экране игры; индексируется МГ, дубли МГЛ — canonical на МГ; robots.txt на GitHub Pages проекта не работает; IndexNow — не для Google.

## Готово, когда
Для каждой игры каталога: своя страница-описание отвечает 200, у неё уникальные title/description, текст 150–300 слов по самой игре, 2–3 настоящих скриншота WebP, OG-обложка, верный canonical, валидный JSON-LD; sitemap содержит только живые страницы; проверка `scripts/platform/verify-seo.mjs` + `mutate-seo.mjs` (≥3 мутации, одна «обман») зелёная. Sitemap подан в Search Console и Bing — это шаг Claude.

## Сначала найди
[PR #242 «SEO: 17 ad-free games…»](https://github.com/mpaykin1/meta6-lab/pull/242) — 49 файлов, давно не обновлялся: влей main, разбей на PR ≤5 файлов (сначала проверка verify/mutate, потом страницы по 3–4 игры, потом sitemap/IndexNow). Workflow-файлы (`seo-catalog.yml`, `seo-indexnow.yml`) — отдельным PR `НУЖЕН CLAUDE`. `progress/seo-claude-games.json` — продолжай с первого несделанного.

## Шаги
1. Число игр бери из каталога (`meta-games/index.html` / `list_games`), не из «17».
2. Описание и управление — только то, что реально есть в игре (открой её и проверь). Скриншоты — снять в браузере с настоящей игры, не рисовать.
3. Одна страница = одна игра; похожие версии (4 острова, 2 Broken City) — либо настоящие отличия, либо canonical на основную.
4. Ссылку владельцу — только после HTTP 200 и наличия SEO-тегов в опубликованном HTML (curl).

## Саморазвитие (после основной работы, обязательно одно)
Новая ловушка в mutate-seo.mjs по реальной ошибке (дубль title, битая ссылка, неверный canonical) или ускорение загрузки страницы (размер картинок, lazy-load) с числом до/после.

## Что это
Отдельная система создания 3D-моделей и миров в стиле INK (живая акварель на Three.js). Владелец просит модель («сделай монстра», «сделай мельницу», «вставь поезд») — ты делаешь её по этой карточке.

## Прочитать перед началом (всё в main)
1. [ink.md](../../ink.md) — стандарт INK и список эталонов.
2. [reference/ink-fallen-guardian/README.md](../../reference/ink-fallen-guardian/README.md) — эталон «Павший великан».
3. [rules/01-stil-i-grafika/RECEPT_INK_MIR.md](../../rules/01-stil-i-grafika/RECEPT_INK_MIR.md) — рецепт: силуэт, материал, палитра, история без текста, масса мелочи, сцена, жизнь слоями, анимация, приёмка.
4. [rules/01-stil-i-grafika/BEZ_PATTERNOV.md](../../rules/01-stil-i-grafika/BEZ_PATTERNOV.md) — без повторяющихся узоров.
Код: [ink-fallen-robot.js](../../reference/ink-fallen-guardian/ink-fallen-robot.js) (как устроен эталон), [shared/ink/ink-template.js](../../shared/ink/ink-template.js) (с чего начинать), паспорт [REFERENCE.json](../../reference/ink-fallen-guardian/REFERENCE.json). Другие эталоны INK (паровоз, оскал, падальщик) — в ink.md; их приёмы можно брать.

## Готово, когда (на каждую модель)
1. Превью `preview/ink-<имя>/` отвечает 200 на ПК и телефоне: модель в акварельном мире, управление пальцем/мышью, 360° осмотр, ЧИСТЫЙ ЭКРАН (только ☰).
2. Рендер — из `reference/ink-fallen-guardian/shared/` без изменений (подключён, не скопирован с правками).
3. Объём со всех сторон; один тёплый акцент; история читается без текста; у персонажа — действия `userData.play(...)`, живое дыхание `userData.updateInk(t)`.
4. `node scripts/visual/verify-no-patterns.mjs preview/ink-<имя>/*` — 0 нарушений; 0 ошибок консоли; FPS ≥ 30 в Chromium 390×844 (честно писать, что это не реальный телефон).
5. Строка в `reports/ink-3d/MODELS.md`: имя, ссылка, что умеет, SHA. Ссылку владельцу — одна строка «поиграть + что нового».
6. В эталоны — только после слова владельца «пасс»; переносит Claude (папка `reference/` защищена).

## Шаги
1. Сначала найди готовое: может, нужная модель уже есть в эталонах или `preview/ink-*` — тогда предложи её. Просят новую — делай новую (эталон не ограничивает новое).
2. Скопируй шаблон в `preview/ink-<имя>/ink-<имя>.js`, свой seed, своя форма. Подключи в `preview/ink-<имя>/index.html` вместе с рендером эталона.
3. Делай по рецепту пп. 1–7, потом анимацию v2 (суставы по цепочке, плавные фазы, без выделения памяти в кадре).
4. Проверки из «Готово, когда» → PR ≤5 файлов → слей сам (не защищённое). Ошибку нашёл — сначала исправь, потом сообщай; каждое «готово» — со ссылкой на SHA/прогон.

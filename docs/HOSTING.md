# Размещение без зависимости от Vercel

Сайт и браузерные игры лаборатории публикуются существующим `LAB Pages` на GitHub Pages.
Боты и проверки работают в GitHub Actions; размещение сайта не заменяет их проверку.

В `vercel.json` отключены автоматические размещения Vercel для всех веток штатной
настройкой `git.deploymentEnabled: false`. Это не удаляет проект Vercel или его
предыдущие размещения. Ручные размещения остаются отдельной операцией.

Документация настройки: https://vercel.com/docs/project-configuration/git-configuration

Никакие результаты Vercel не подменяются успешными статусами. Проверки кода,
ассетов, браузера, защиты исходников и очереди остаются включёнными.
Если в настройках GitHub отдельно требуется именно Vercel, владелец настройки
должен заменить это требование проверкой фактического размещения GitHub Pages.
Доступ к административным настройкам не нужен для самой настройки в репозитории.

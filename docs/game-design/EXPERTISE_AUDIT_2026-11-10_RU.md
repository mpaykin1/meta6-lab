## Главная гипотеза
Сильная идентичность META GAMES: мрачные миры, туман, одиночество, превращение окружения, возвращение света, памяти и жизни. Общая формула игрового цикла: **заметить загадку → выполнить простое действие → увидеть физическое изменение мира → получить новую возможность → исследовать дальше**. Не унифицировать жанры; унифицировать ясность причин и последствий.

## Антипаттерны («обучение через обосранные штаны»)
1. Атака из тумана без предупреждения → звук + тень + направление до удара.
2. Десятки предметов сразу → сначала один предмет, затем один новый за этап.
3. Неясный маршрут → один доминирующий видимый ориентир.
4. Полный сброс после смерти → сохранять освоенные открытия и возвращать к ближайшему этапу, если жанр позволяет.
5. Предмет без понятного результата → действие → эффект/звук → наблюдаемая польза.
6. Случайная непроходимая раскладка → генерация вокруг гарантированного маршрута и проверка проходимости.
7. Пустой старт как ощущение незавершённости → минимум объектов, но выразительная атмосфера, движение, цель.
8. Низкий FPS и задержка ввода → адаптивная нагрузка без изменения отклика управления.
9. Слишком много полива ради числа стадий → новые способы взаимодействия и пространственные изменения, не только шкала роста.
10. Слишком много маркеров и текстов → один навигационный сигнал в конкретный момент.

# Train in the Fog — канонический производственный список 640 ассетов

**Статус:** художественный стандарт **CINEMATIC VOXEL NOIR**. Список из 640 позиций сохранён без сокращений. Обязательный контракт: [META_GAMES_AUTONOMOUS_ASSET_PACK_SPEC_V1_RU.md](../../standards/META_GAMES_AUTONOMOUS_ASSET_PACK_SPEC_V1_RU.md), особенно раздел 15.

**Художественный эталон:** три оригинальных вертикальных эскиза владельца: поезд у платформы; поезд в ночном лесу с сигналом; поезд в плотном тумане с прожектором. Три референса уже загружены в `assets/train-in-the-fog/references/` и сопоставлены с R1/R2/R3 в [REFERENCE_FRAMES_R1_R2_R3_RU.md](REFERENCE_FRAMES_R1_R2_R3_RU.md). Художественное соответствие моделей по ним ещё не подтверждено.

**Масштаб:** 32 категории × 20 = **640 уникальных базовых позиций**; 2500–4000 файлов/кадров/ракурсов/LOD — плановый объём, не критерий качества. Каждая строка с кодом NN.NN остаётся отдельной производственной позицией. Визуальные эффекты могут быть GLSL, а не PNG; звук учитывается отдельно.

### Минимальный комплект визуальных доказательств для каждой ключевой позиции

- `referenceId`: R1, R2, R3 или их комбинация; `referenceCrop`: конкретная область эталона.
- `heroView`: скриншот ассета **в основной сцене** с соответствующей перспективой, туманом и освещением; одиночный viewer не засчитывается.
- `silhouetteMatch`: проверка формы, пропорций и визуального масштаба.
- `materialMatch`: мокрые PBR-материалы, износ, фактура, отражения, нужные источники света.
- `compositionMatch`: положение в кадре и перекрытие другими слоями.
- `artReview`: `NOT_VERIFIED` / `REJECTED` / `ACCEPTED` с ссылкой на сравнительный кадр; без сравнительного кадра `ACCEPTED` запрещён.

**Первый художественный gate:** 13–16 (локомотив и вагоны) + 06 (рельсы) + 07–12 (станция, сигнал, фонари) + 02/04/05/23–26 (туман, вода, лес, материалы). Сначала совместный кадр R1; затем R2 и R3. Нельзя повышать художественную готовность за счёт дополнительных полигонов, UI или технического viewer.


## Обязательный контракт каждой позиции NN.NN

В asset-manifest.json для **каждой из 640 позиций** обязательны поля: `id`, `name`, `category`, `assetType`, `sourceFiles`, `runtimeFiles`, `referenceIds`, `geometryDetail`, `materials`, `lighting`, `animationClips`, `collision`, `sockets`, `lod`, `scenePlacement`, `mobileBudget`, `acceptance`, `status`. Отсутствующие данные отмечать `null`/WIP, **не выдумывать**.

**Правило по типу:**
- **3D GLB + исходник:** локомотив, вагоны, рельсы, шпалы, сигналы, фонари, здания, платформы, мосты, деревья и крупные объекты. Настоящая объёмная геометрия, не плоская карточка/иконка.
- **2.5D:** дальний лес, холмы, некоторые архитектурные слои и второстепенные объекты, если сохранены параллакс, перспектива, освещение и объёмная глубина.
- **PBR-материалы/атласы:** мокрый металл, ржавчина, дерево, гравий, грязь, стекло, бетон; albedo, roughness, metalness, normal/emissive по необходимости. Не заменять материальность однотонными заливками.
- **GLSL/частицы/системы:** объёмный туман, рассеяние света фар, дождь, дым, отражения, рябь и световые события. Не рисовать прожектор непрозрачным треугольником.
- **2D PNG/спрайт-листы:** интерфейс, мелкие детали и отдельные эффекты. Для движущихся объектов обязательны реальные различающиеся кадры или процедурная анимация.

Камера на уровне рельсов, ведущие диагонали, холодная графитовая палитра и тёплые окна. Проверять фактический игровой скриншот рядом с оригинальными эскизами.

**P1:** анимация поезда/тележек, пар, капли, сигналы, свет, взаимодействия и коллизии P0-объектов. **P2:** расширение мира, интерьеры, персонажи и предметы. **P3:** вторичные варианты, декали, UI и дополнительные эффекты. Приоритет не отменяет ни одну из 640 позиций.

## Критерии приёмки — каждый ассет, не количество файлов

**30 баллов:** визуальное соответствие эскизам (силуэт, масштаб, композиция, цвет, атмосфера). **25:** качество геометрии и материалов. **20:** интеграция в основной игровой мир, корректные коллизии/координаты. **15:** необходимые анимации, световые события и взаимодействия. **10:** подтверждённая работа и производительность на целевых устройствах. **Непроверенное = 0 подтверждённых баллов.**

**Запрещено:** принимать SVG-макеты, плоский локомотив, треугольный луч, одинаковые геометрические деревья, линии вместо рельсов, пустые анимационные кадры, GLB только в viewer, отсутствие мокрых материалов или тумана как полноценные ассеты. Партия не считается законченной без визуальной приёмки контрольной сцены. Оценки 90–100% без фактической проверки недопустимы.

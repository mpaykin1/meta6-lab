## Визуальная система — использовать целиком

- **Глубина:** чёрная вода, глубинный цвет, дальние силуэты, объёмная дымка; интенсивность тумана и световой экспозиции зависит от глубины.
- **Средний план:** GPU-инстансированные спрайты, отражающие свет по normal map; косяки рыб, медузы, биолюминесценция, интерактивные существа.
- **Ближний план:** водоросли, крупные существа, реагирующие спрайты, частицы и свет героя; часть передних объектов становится прозрачной рядом с героем.
- **Экран:** рендер в render target → выделение засветки → двухпроходное размытие → финальная компоновка; цветокоррекция, свечение, хроматическая аберрация, шум/глитч, затемнение, мягкая глубина резкости.

**Неповторяемые детали рендера:** карта нормалей в спрайтовом шейдере; покадровый выбор анимации из атласа; индивидуальные seed/phase/flip/amp/rotation; GPU instancing для нескольких групп; плавное затухание и растворение; камера с инерцией и отставанием от движения; динамический источник света у рыбы; прогрессивная перестройка освещения и атмосферы по глубине.

**Точные точки в исходнике:** `requestAnimationFrame(q0)`; `ge.uLightPos`, `ge.uLightR`, `ge.uExpo`, `ge.uFog`, `ge.uDark`; `ag.begin/push/end`, `pt.begin/push/end`, `sP.begin/push/end`; последовательность `ye.setRenderTarget(YQ)`, `ye.render(xD,nD)`, `MQ(f0,oD)`, `MQ(ct,HC)`, `MQ(ct,oD)`, `MQ(CD,null)`. Звук — генерация через Web Audio API.

**Управление:** палец или курсор; клавиши WASD/стрелки. Экран фиксирован, HTML сохраняет автономность.

**Стороннее:** сборка включает Three.js с указанной в исходнике лицензией MIT; атрибуцию сохранять. Перед распространением отдельного фрагмента проверить его происхождение и лицензию. Статус визуального эталона не равен автоматическому OWNER PASS для переделок.

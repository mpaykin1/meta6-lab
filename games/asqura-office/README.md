# ASQURA Office — графический и анимационный эталон

**Оригинал владельца:** `index.html`, SHA-256 `8b675a4980a797f5688b3a380bb1ce7f31c4ac9feae5268048817b0b4b9f13f4`. Не изменять оригинальную сборку.

## Пиксельная 2.5D-архитектура

- **Экран:** Canvas 2D с небольшим внутренним буфером, `imageSmoothingEnabled=false`, `image-rendering:pixelated`; масштаб через целые пиксельные блоки `K`.
- **Проекция:** изометрия `P(x,y,z)`; базис `(x-y)*.83*S` по X и `((x+y)*.39-z)*S` по Y. `UP` — обратная проекция для касаний.
- **Объём:** `box` рисует верхнюю, переднюю и боковую грани; `floorT`, `backT`, `sideT` дают отдельные плоскости для пола и стен.
- **Персонажи:** `chibi` рисует 14×22 арт-пикселя; отдельные детали волос, лица, костюма и тени; фазы шага, печать, поднятая рука, дыхание, сон, моргание и смена направления.
- **Мир:** заранее созданная текстура ночного города `SKY`; офисная мебель и реквизит процедурно прорисованы функциями `drawDesk`, `drawChair`, `drawPlant`, `drawPrinter`, `drawCoffee`, `drawCooler`, `drawCabinet`.
- **Глубина:** планировка и сортировка предметов и персонажей; ближний план — сотрудники/частицы, дальний — силуэты ночных зданий и окна.
- **Постобработка:** `vign` (радиальная виньетка), `NOISE` и `grainPat` (тонкое зерно), `drawDust`, частицы, индикаторы.
- **Анимация/игра:** `frame` → `update(dt)` → `render()`; `makeWorkers`, `updWorker`, `director` контролируют сотрудников и сюжетные события; `sparks`/`puff` — визуальные эффекты.
- **Звук:** собственный синтез через Web Audio API; камера перемещается перетаскиванием, по персонажам можно нажимать.

**Никаких PNG в исходном HTML:** спрайты, декорации, освещение и интерфейс формируются кодом Canvas 2D. Не заменять их эмодзи, CSS-фигурами или чужими изображениями. Основной воспроизводимый ассет — функция `chibi` вместе с `CAST` и палитрами; для точного переноса брать из оригинала.

**Внешняя зависимость:** шрифт `Press Start 2P` загружается с Google Fonts, с предусмотренным запасным моноширинным шрифтом; для идеальной офлайн-идентичности нужна легальная локальная копия шрифта. Игра не использует WebGL.

**Повторное использование:** соблюдать исходные пропорции и палитры, шаги анимации и порядок рисования; не смешивать эту Canvas-проекцию с перспективной WebGL-сценой ABYSS GLOW, пока не требуется осознанный гибрид.

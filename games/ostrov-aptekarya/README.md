# Остров последнего аптекаря · Глава I «Тихолист»

Играть: https://mpaykin1.github.io/meta6-lab/games/ostrov-aptekarya/

Мистическое демо в мире INK «Павший великан» (эталон `reference/ink-fallen-guardian/`, импортируется без изменений).
Утром аптекарь и девочка Ива идут в лес за травами, грибами и водой; из их разговоров открывается лор.
Нужно вернуться до темноты — иначе у Ивы начнётся сбой импланта, и она погонит аптекаря к спящему великану.

- Этапы производства с кодом (учебник для GPT): [STAGES.md](STAGES.md)
- Полный сюжет: [LORE.md](LORE.md)
- Файлы: `game.js` (сюжет и цикл), `girl.js` (Ива и её ИИ), `dialogue.js` (все реплики), `post.js`, `audio.js`, `ui.js`, `bot/playthrough.mjs`.

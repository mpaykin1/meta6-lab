# «Остров последнего аптекаря» — этапы производства (учебник для GPT)

Демо «Глава I · Тихолист» собрано Claude 13.11.2026 по этим этапам. Играть: https://mpaykin1.github.io/meta6-lab/games/ostrov-aptekarya/
Сюжет целиком: [LORE.md](LORE.md). Задача GPT — пройти те же этапы для глав II–V и довести игру до конца сюжета.

**Главное правило игры:** не усложняй геометрию — усложняй атмосферу. Лор подаётся только диалогами Ивы и аптекаря, а не текстом на экране.

## Этап 0. Выбрать играбельное ядро из лора

Лор длинный. В главу берётся **одна** экшн‑идея + то, что к ней подводит. Для главы I:

| Из лора | В демо | Почему |
|---|---|---|
| Аптекарь каждое утро собирает травы | поход в лес: 3 тихолиста, 2 сонника, вода с причала | спокойный ритм, знакомство с миром |
| Девочка с имплантом, «пациент номер один» | Ива идёт рядом и разговаривает | через диалоги игрок узнаёт лор |
| Приступы, преследование, ведёт к роботу | сумерки → сбой → погоня, тянет к великану | главное действие |
| «Доктор. Вы опоздали на 83 года» | реплика, если Ива дотащила до робота | удар по нервам |
| Записка «Вылечи того, кто лежит в лесу» | финальный поворот главы | крючок на главу II |

Остальное (архив, госпиталь, болезнь протезов, ядро) — главы II–V (см. конец файла).

**Проверка этапа:** в главе ровно одна новая механика‑ядро; всё остальное — подводка к ней.

## Этап 2. Герой: движение с инерцией, тяжёлая камера

Никаких `position.copy(...)` рывками. Скорость догоняет желаемую через экспоненциальный LERP, независимый от FPS.

```js
const damp = (k, dt) => 1 - Math.exp(-k * dt);
const want = V(Math.cos(yaw)*mx + Math.sin(yaw)*my, -Math.sin(yaw)*mx + Math.cos(yaw)*my).multiplyScalar(3.1);
heroVel.lerp(want, damp(9, dt));                 // инерция
if (canWalk(nx, hero.position.z)) hero.position.x = nx;   // скольжение вдоль стен
if (canWalk(hero.position.x, nz)) hero.position.z = nz;
focus.lerp(desired, damp(3.6, dt));              // камера запаздывает = «тяжёлая»
```
Камера ортографическая из эталона (`createIllustrationCamera`), высота кадра плавно меняется: прогулка — ближе, погоня — дальше. Для портретного телефона учитывать `aspect`:
```js
const baseH = Math.max(10, 7.2 / aspect) * (chase ? 1.32 : 1) / zoom;
viewH += (baseH - viewH) * damp(1.4, dt);
```
**Ловушка (была ошибка):** на телефоне `14 / aspect` давало кадр в 25 единиц — герои превращались в точки. Проверять скриншотом 390×844.

const implant = /* сфера MeshBasicMaterial, userData.watercolorSkipWash = true */;

## Этап 4. Диалоги — данные отдельно, движок отдельно

Все реплики — в `dialogue.js` ключами. Движок — очередь в `game.js`. Новая глава = новые ключи, старые не переписывать.

```js
// dialogue.js
export const SCRIPT = {
  herb2: [['i', 'Пахнет дождём. Откуда тут столько редких растений?'],
          ['a', 'Здесь была ботаническая станция…']],
};
// game.js
function play(key, then, interrupt = false) {
  const lines = SCRIPT[key] || key;
  if (interrupt) { dlg.queue.length = 0; dlg.cur = null; }
  lines.forEach((line, i) => dlg.queue.push({line, then: i === lines.length - 1 ? then : null}));
}
// длительность реплики: 1.7 c + 0.052 c на букву; тап по реплике — пропуск
```
Три вида триггеров:
1. **Событие** — подобрал траву → `play('herb' + counts.herbs)`.
2. **Место** — подошёл к роботу/воротам/лисе (один раз, когда никто не говорит):
```js
const near = (k, p, r) => { if (!flags[k] && !busy() && flat(hero.position, p) < r) { flags[k] = true; return true; } return false; };
if (near('robot', ROBOT, 8.2)) { iva.set('listen', 14); play('robot', () => iva.set('follow')); }
```
3. **Тишина** — 19 с без слов → следующая фоновая пара из `AMBIENT` (без повторов).

Голос великана (`'v'`) — тёмная плашка, моноширинный дрожащий шрифт, синтез речи (если есть русский голос) + глитч на экране.

**Правило:** каждая реплика либо раскрывает лор, либо даёт подсказку, либо создаёт тревогу («вернуться до сбоя»). Пустой болтовни нет.

## Этап 5. Сбор — этапы открываются постепенно (ПОСТЕПЕННО)

Цели показываются маяками в мире (столб света + кольцо), не текстом. Следующий вид предметов появляется только после предыдущего.

```js
function take(it) {
  if (it.kind === 'herb') { counts.herbs++; play('herb' + counts.herbs);
    if (counts.herbs === 3) { stage = 2; shrooms.forEach(s => { s.obj.visible = true; s.beacon.userData.want = 1; }); } }
  else if (it.kind === 'shroom') { counts.shrooms++; charges++;   // сонник = заряд пыльцы
    if (counts.shrooms === 2) { stage = 3; waterBeacon.userData.want = 1; } }
}
```
БЕЗ ПОВТОРОВ: места трав и сонника каждый раз выбираются заново (3 из 7 и 2 из 5), `layoutHash` отдаётся боту.
```js
const pickN = (arr, n) => arr.map((v, i) => [Math.random(), i]).sort((a, b) => a[0] - b[0]).slice(0, n).map(([, i]) => i);
```
Травы можно собирать сразу, пока идёт вступительный разговор — игрок не ждёт.

Каждая вещь даёт пользу (ПОНЯТНАЯ ПОЛЬЗА): сонник → кнопка пыльцы появляется с первым грибом и реально усыпляет Иву. Предметы — из генераторов эталона (`wildflowers`, `mushrooms`) с перекраской.

## Этап 6. Время как таймер тревоги

`day` растёт 0→1 за ~5 минут. Свет, туман, пост‑обработка, музыка и огонёк импланта следуют за ним. Реплики `dusk1`/`dusk2` напоминают «вернуться до сбоя». Если не успели — сбой начинается где стоим (`tellLate`).

```js
day = Math.min(1, day + dt / (stage === 4 ? 9 : 320));
ambient.color.set('#fff3d7').lerp(new T.Color('#aeb8d4'), dusk);
if (day >= 1 && stage < 4) startTell(true);
```

## Этап 7. Погоня — конечный автомат Ивы

Состояния (`girl.js`): `follow → listen → tell → chase ⇄ lunge → grab → (stun | sleep → rise) → faint/idle`.

```js
} else if (s.mode === 'chase') {
  // «Доставка врача»: встать между врачом и домом, прижимать к лесу и великану
  const lead = P.clone().addScaledVector(ctx.heroVel, .45);
  const toHome = new T.Vector3(ctx.home.x - P.x, 0, ctx.home.z - P.z).setLength(1.35);
  const target = dist < 3 ? lead : lead.add(toHome);
  s.speed = dist > 5 ? 4.6 : Math.min(3.55, 3.2 + s.chaseTime * .008); // далеко — «программный» бег
  if (dist < 2.5 && s.lungeCd <= 0) set('lunge');                      // бросок 6.1 ед/с на 0.32 с
}
```
Аптекарь её не бьёт (лор): только убегает, обходит, сыплет пыльцу (`sleep` 4.6 с) или вырывается (частые рывки джойстиком/кнопкой). Если дотащила до великана — «ВЫ ОПОЗДАЛИ НА 83 ГОДА», затемнение, повтор погони с того же места. Добежал до двери аптеки — победа. 70 с ночи (вместе с захватами) — Ива падает без сил (лор: «теряет сознание»).

**Ловушка (была ошибка):** при скорости Ивы ниже скорости аптекаря бот ни разу не был пойман — погони не было. Баланс проверять ботом в двух режимах: «защищается» (должен победить) и «пассивный» (должен быть пойман и вернуться на чекпойнт).

## Этап 8. Пост‑обработка поверх принятой оптики

`ink-optics.js` эталона рисует «на экран». Его не трогаем — на время подменяем экран своим таргетом:

```js
const original = renderer.setRenderTarget.bind(renderer);
renderer.setRenderTarget = (rt, ...r) => original(rt === null && redirect ? redirect : rt, ...r);
redirect = target; optics.render(scene, camera, false); redirect = null;
original(null); renderer.render(postScene, postCamera);   // наш шейдер
```
Шейдер (`post.js`): хроматическая аберрация от центра, глитч строк, зерно, чернильная виньетка, сумеречный тон, затемнение. Все силы — uniform‑«рычаги»: `signal`, `glitch`, `dusk`, `fade`, `warm` — связаны с состоянием сюжета, а не константы.

## Этап 11. Бот‑проходчик и проверки

Игра отдаёт API `window.__APTEKAR__`: `start()`, `debugChase()`, `bot`, `botPassive`, `timeScale`, `state`, `stage`, `girl`, `caughtCount`.

Для общего бота МГЛ (`scripts/meta-bot`) есть своя ручка `bot-adapter.js` → `window.__META_BOT__` (только чтение, `Object.freeze`), стратегия `bot-strategy.mjs` и `bot.json`. Уровень 0 — поход (цель = текущий маяк), уровень 1 — погоня (цель = дверь аптеки). `progress` = услышанные реплики + собранное, поэтому разговор без цели не считается «застреванием».
`bot.json` → `"skipChecks": ["cleanScreen"]` — **единственное исключение и только из‑за диалогов** (решение владельца 13.11.2026: лор через реплики). Любой другой текст на экране по‑прежнему запрещён — его ловит наш `bot/playthrough.mjs`.

**Ловушка (была ошибка):** в CI (программный WebGL) мир INK идёт 2–3 FPS. При шаге кадра, обрезанном до 50 мс, игра шла в 6 раз медленнее, и бот «застревал». Решение — симуляция подшагами, рисование отдельно:
```js
const steps = Math.min(8, Math.max(1, Math.ceil(dt / .05)));
for (let k = 0; k < steps; k++) simulate(dt / steps, mx, my);   // логика всегда в реальном времени
```

**Ловушка (была ошибка):** `Object.assign(api, {get state(){…}})` копирует значение, а не геттер — бот видел вечное `title`. Только `Object.defineProperties(api, Object.getOwnPropertyDescriptors({...}))`.

**Ловушка главы II (13.11.2026):** проверка бота не считается прохождением двери, если движок сам вызывает `chapter2.action()` из `botInput`. Бот обязан идти до створки и нажать настоящую игровую кнопку (пробел/иконка). Защита — `bot/inventory.mjs` и три мутации в `bot/mutate-inventory.mjs`; `bot/playthrough.mjs` проверяет три страницы и минимум одну закрытую дверь. Скриншоты — мобильный 390×844 и ПК.


Запуск локально (Chrome + Playwright есть в репозитории):
```bash
python3 -m http.server 8765 &      # из корня meta6-lab
node games/ostrov-aptekarya/bot/playthrough.mjs full      # вся глава: старт → финал
node games/ostrov-aptekarya/bot/playthrough.mjs chase     # погоня, бот защищается → финал
node games/ostrov-aptekarya/bot/playthrough.mjs passive   # погоня, бот не защищается → пойман → чекпойнт
```
PASS бота = 0 ошибок страницы, нужное конечное состояние, нет текста вне диалога. Результат 13.11.2026: full — финал; chase — финал; passive — пойман 1 раз, повтор погони.

# Как продолжать: главы II–V

Каждая глава проходит этапы 0–12. Ассеты — **только** из эталонов (INK‑генераторы, робот, здания, звери). Каждая глава приносит **новую** механику и **неожиданный** поворот — главы не должны быть похожи.

| Глава | Ядро (экшн) | Новые реплики‑ключи | Поворот в конце |
|---|---|---|---|
| II «Архив станции» | Ночная прятка: Ива бродит во сне по станции, аптекарь ищет 3 страницы архива и прячется за дверьми (закрыть дверь = выиграть секунды) | `archive1..3`, `sleepwalk`, `doorShut` | Страница: «Объект П‑1 — передвижной госпиталь». Великан не боевая машина |
| III «Лодки» | День приёма: приплывают люди с протезами; аптекарь готовит настойку по рецепту (смешать 2 из 3 трав за время), а протез одного пациента начинает сам хватать вещи | `boat1..3`, `patientTwitch`, `prostheticNetwork` | У пациентов те же сбои, что у Ивы: детали протезов слушают старую машинную сеть |
| IV «Внутри великана» | Спуск через пробоину: затопленные коридоры, аварийный свет, Ива — «ключ» к дверям (подключение = риск приступа, огонёк импланта = таймер) | `inside1..`, `identified` («АПТЕКАРЬ. ОБЪЕКТ ОПОЗНАН») | Станция была частью госпиталя; аптекарь всю жизнь поддерживал его, не зная |
| V «Выбор» | Финал: удержать Иву в сознании (сонник/тихолист по ритму) пока госпиталь освобождает протезы от сети | `choice`, `release`, `morning` | Великан тратит последние силы; глаза загораются; утром лодки везут учеников |

Порядок для каждой главы: новая папка/ключи → инвентаризация того, что уже есть в главе I (ничего не терять) → этапы 4–11 → бот проходит → PR → `200`.

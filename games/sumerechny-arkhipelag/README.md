## Эталонные составляющие

- Воксельный архипелаг 256×256×40, восемь островов с разными биомами.
- Текстурный атлас и спрайты, встроенные в исходный HTML (base64); пиксельные вода, небо, туман и сияние на GLSL.
- Анимированный кит, маяки, прилив, реликвии, частицы, миникарта, мобильное и клавиатурное управление.
- Three.js, EffectComposer / UnrealBloomPass и набор шейдерных постэффектов.

**Оригинал сохраняется для побайтового повторного использования;** рабочую копию не считать неизменённым исходником. Сторонние зависимости требуют проверки лицензий; до неё не отмечать их как `rights_verified`. Главные игры и другие эталоны не изменены.

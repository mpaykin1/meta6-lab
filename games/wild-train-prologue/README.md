## Что это за игра
1. **Погоня (вид 1).** Ковбой на лошади из модели владельца `Cowboy_1.fbx` скачет по закатной пустыне. Камера — прицел: игрок крутит её пальцем, тап по цели — выстрел. Рука с револьвером поворачивается к цели, пуля летит из дула по прямой. Каждое попадание ускоряет галоп.
2. **ПОСТЕПЕННО:** сначала бутылки → после 5 бутылок бандиты сзади (красный блеск перед выстрелом) → после 4 бандитов вороны пикируют с неба.
3. **Сияющая буква → вид сверху (вид 2)** по эскизу владельца: красная земля, бандиты окружают кольцом, буквы S E A R W D меняют стрельбу (спираль, эхо-кольцо, веер, рикошет, выстрел назад, дуплет), D+R+A+W = дуэль с замедлением. Проиграл — камера опускается обратно в погоню.
4. **Музыка владельца** (`sfx/music.mp3`, трек владельца) — только в виде сверху: куски с разных мест, иногда задом наперёд, с паузами.
5. **Удержание без рекламы** (R1–R11 кроме рекламы): мгновенный старт, полоса загрузки без текста, стрелка-подсказка без слов, подарок дня (ранняя буква), бесплатное возрождение раз за попытку вместо «за рекламу», пауза на P, сохранение в браузере, счётчик `window.__INV()`.

## Где в коде что лежит (для склада `shared/`)
| Решение | Где |
|---|---|
| Процедурный риг без скелета (ноги, голова, хвост, рука, всадник — маски вершин + вершинный шейдер) | `makeRigMat()`, `loadModel()` |
| Прицеливание руки по-настоящему (итеративный решатель yaw/roll по стволу) | `solveAim()`, `fireNow()` |
| Пули-снаряды по прямой с проверкой отрезок–сфера | `shootBullet()`, `stepBullets()`, `segHit()` |
| Кран камеры между погоней и видом сверху | `update()` → блок `camera` |
| Мир, бегущий в любую сторону (2D-прокрутка земли и инстансов в шейдере) | `wrapMaterial()`, `groundMat` |
| Музыкальный режиссёр (фразы, реверс, паузы) | `musicDirector` |
| Ворона владельца (6 кадров GIF как спрайт) | `spawnCrow()`, `crowFrame()` |
| INK-ворон из МГЛ (`demos/living-watercolor/ink-flying-raven.js`, без изменений) | `createInkRaven` |
| Звук на iPhone (п. 15 ЗВУК) | `unlockAudio()` |

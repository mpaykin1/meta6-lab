Connect / Local MCP

Connect worlds.

Подключите игры и исходники META GAMES к своему ИИ через локальный MCP. Бесплатно: сервер запускается на вашем компьютере через stdio, без облачного сервера и API-ключей.

1. Скачайте проект

Нужны Node.js и Git. Выполните команду в терминале:

git clone https://github.com/mpaykin1/meta6-lab.git
cd meta6-lab
node shared/approved/mcp.mjs

Последняя строка запускает MCP в терминале; остановите её Ctrl+C. В самом ИИ-клиенте MCP запускается автоматически. Никакие npm-пакеты для сервера не требуются.

2. Укажите путь к папке

Не путь к файлу, а к папке проекта. Конфигурации ниже будут собраны автоматически. Путь остаётся в вашем браузере.

3. Подключите своего клиента

Claude Desktop

Откройте claude_desktop_config.json: Windows — %APPDATA%\Claude\, macOS — ~/Library/Application Support/Claude/. Добавьте запись в mcpServers и перезапустите приложение.







Cursor


Добавьте конфигурацию в .cursor/mcp.json проекта или в настройки MCP Cursor, затем включите сервер.








Claude Code


Выполните команду в терминале. Затем откройте /mcp для проверки соединения.








VS Code и другие MCP-клиенты


Для VS Code — .vscode/mcp.json. Для других stdio-клиентов используйте ту же команду node и абсолютный путь к shared/approved/mcp.mjs.

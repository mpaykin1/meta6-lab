## Укрепление процесса
- Аудитор теперь отбрасывает неподходящий Actions (SHA, имя workflow, repo, status, conclusion). Открытый PR, skipped CI или успешный CI для другого кода не засчитывается.
- Подтверждение исходников проверяется в ветке main/master на момент аудита; GitHub Contents API возвращает файл объектом, а каталог массивом — оба случая обрабатываются. Запросы по одинаковым PR и запускам кэшируются.
- CI блокирует завышенные вручную проценты в score.json и несоответствия в полной таблице REPORT.md.
- Отчёт отражает 10 категорий вместо прежних трёх. Старые 23% по трём категориям и новые 9% по десяти нельзя напрямую сравнивать как изменение скорости работ.

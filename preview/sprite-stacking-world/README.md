## Один запуск
1. Проверить фактическую доступность авторских скилов, исполнения, GitHub. Прочитать AGENTS.md и automation/asset-check/SPEC.md §SPRITE-STACK. Проверить свежий HEAD интеграционной ветки и открытые PR. При недоступности чтения GitHub можно читать публичные исходники по raw URL; это не доказывает права записи.
2. Ассет = текстовый рецепт `recipe.json` по [automation/stackgen/README.md](../../automation/stackgen/README.md). Скилы, Plugin Creator, генерация картинок и запуск кода НЕ нужны: прогон GitHub Actions `stackgen` сам рисует RGBA-срезы, `stack.json`, превью 8 углов и отчёт HARD/SOFT. Готовность = зелёный stackgen (HARD 0) + ассет виден в игре.
3. Ветка кандидата от свежей общей ветки: lab/stack-<lane>-<unique-id>. Работать только в своей новой папке пакета asset-packs/incoming/stack-<lane>-<unique-id>/, включающей настоящие RGBA-срезы, stack.json в существующем формате mg-spritestack/1, provenance, license, копию index.html с видимым ассетом и при необходимости анимацию. Ветку/PR создавать только с реальным ассетом. Не терять ранее добавленные объекты.
4. Проверка существующим ASSET CHECK и визуально в игре; HARD=0 и зелёный ASSET CHECK до переноса в ready. Не ослаблять проверки. Наличие файла не означает наличие объекта в игровом кадре. Применять требования FINISH, КОНТУР, ТЕЛЕФОН БЕЗ ТОРМОЗОВ, living world; проверять 390×844/844×390. Соблюдать права на распространение.
5. Открывать PR кандидата в интеграционную ветку. Только E (Skill Nexus) последовательно интегрирует прошедшие проверки ассеты в общую игровую копию, сохраняя все предыдущие; перед каждым изменением перечитывает HEAD, разрешает конфликты без force-push, не сливает непроверенное. Если правила GitHub не допускают слияние — оставить проверяемый PR для Codex/Claude, не обходить защиту.
6. Один общий PR интеграционной ветки в main. Публиковать через существующий Pages только после разрешённого merge и реального HTTP 200 + визуальной проверки актуальной версии; постоянный целевой URL https://mpaykin1.github.io/meta6-lab/preview/sprite-stacking-world/ . Не заявлять, что URL работает, пока не проверен. До слияния выдавать ссылку на PR и чёткий статус.
7. Если нет записи в GitHub — сообщить «write denied» с попыткой; скилы для этого конвейера не требуются.

# META GAMES — 10 оригинальных эталонов графики и анимации (08.11.2026)
Десять HTML загружены владельцем напрямую. Они сохраняются без изменения логики, шейдеров, пиксельных текстур и анимации. **Это донорская библиотека**, а не автоматически проверенные игровые релизы.
## Как воспроизводить качество
- Сцена: настоящая перспективная WebGL 3D камера и глубинные слои: фон, дальние силуэты, объёмная дымка, средний план с основными формами, передний план с деталями, экранный постэффект.
- Не заменять 3D диораму плоской Canvas-заставкой. Использовать nearest-filtered 16×16 атласы как текстуры и billboards в пространстве, с нормальным масштабом, коллизиями, плавной камерой.
- Свечение: emissive materials + GPU bloom; атмосфера: туман, эффекты воды, частицы, анимация светящихся объектов; cinematic pipeline: render → bloom → DOF → color/CRT; этот принцип показан у Twilight / Underup / Sunken City.
- Оптимизация: InstancedMesh/инстансинг для растительности и повторяющихся объектов, отбор видимого, кэширование геометрии и материалов.
- Демоническая кисть: собственный WebGL2 / GLSL ES 300 с суставами; это источник для скелетной и процедурной графики, не 2D картинка.
- ASQURA: пиксельный офис с независимой анимацией персонажей и игровыми событиями, звук синтезируется WebAudio.
- Пепельный путь: voxel → sprite stack / billboard; 2.5D из пиксельных GPU-текстур, покадровая анимация, процедурные карточки травы, инстансинг.
- «Затонувший город»: 76 семейств 3D-моделей, разные версии 2D/2.5D/3D, glow masks, 16×16 тайлы и manifest.json в локальном ZIP-паке.
## Как использовать
1. Выбрать конкретный источник и записать в новый проект его `id` и версию SHA из `catalog.json`.
2. Копировать оригинальные пригодные компоненты: геометрию, текстуры, материалы, шейдеры и поведение; не заменять на заглушки.
3. Сохранять перспективу, работу bloom/DOF, NEAREST, интерактивность, мобильное управление.
4. Отделять собственные исходники от сторонних библиотек. Право на сторонний код/ассеты подтверждать отдельно.
5. Изменения делать в отдельной копии/игре. Эталонные исходники никогда не переписывать.
## Границы текущей загрузки
Все 10 HTML и 4 приложенных MD перенесены в GitHub. `water.html` сохранён как 10 точных частей, загружается loader'ом через fetch и проверяет SHA-256 перед запуском. Из оригинального `water.html` в GitHub восстановлены **114 бинарных GLB-моделей**, **12 исходных PNG-атласов** и **951 PNG-спрайт**, вырезанный из этих атласов без изменения пикселей. Имена, пути, кадры и FPS хранятся в [`sunken-city/asset-index.json`](sunken-city/asset-index.json), точные хеши восстановленных файлов — в [`sunken-city/pack-artifacts.json`](sunken-city/pack-artifacts.json). Отдельный архив `sunken-city-pack(2).zip` с 1405 файлами ещё не загружен в GitHub целиком; дополнительные VOX/OBJ/MTL и часть PNG в каталоге отсутствуют. Поэтому это **не полное зеркало ZIP**, но доступная для повторного использования библиотека моделей и анимаций.
Этот каталог находится в песочнице `meta6-lab` и не означает релиз в основном `meta6` или подключение публичного MCP.

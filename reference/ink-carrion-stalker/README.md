# INK · Падальщик — объёмная 3D-модель (OWNER PASS, 15.11.2026)

Решение владельца: «добавь эту модель как эталон на мг и мгл».

Это оригинальная объёмная биомеханическая модель по предоставленному GIF (не спрайт, не GIF в сцене). Комбинация акварельной плоти, мехатронных суставов, крупных лап с длинными когтями, объёмных зубов и шарнирной нижней челюсти.

## Просмотр
- МГЛ: https://mpaykin1.github.io/meta6-lab/reference/ink-carrion-stalker/
- МГ: https://mpaykin1.github.io/meta6/reference/ink-carrion-stalker/ (публикация после разрешённого переноса из МГЛ)
- Действия: `userData.play('bite'|'jump'|'strike'|'prowl')`.
- Вращение камеры 360°, масштаб мышью и двумя пальцами, виды всего тела/головы/ног; цветная и Ч/Б акварель.

## Повторное использование
- Исходник: `ink-carrion-stalker.js`, экспорт `createInkCarrionStalker(seed)`, THREE.Group.
- Сцена: `scene.js`; точка входа: `index.html`.
- Reuse без копирования рендера: соседний неизменный эталон `../ink-fallen-guardian/` (Three.js 0.165.0 MIT и акварельные генераторы/шейдеры без паттернов).
- Папка готова к копированию как единое целое `reference/ink-carrion-stalker/` между МГЛ и МГ без изменения относительных путей.
- Новые модели создаются в отдельных модулях; принятые модели никогда не изменять для новых экспериментов.
- Этот эталон — графический ассет, не отдельная игра.

Первоначальная ветка: `lab/ink-carrion-stalker-3d-20261115`, PR #332.

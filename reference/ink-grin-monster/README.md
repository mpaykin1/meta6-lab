## Что принято
- Объёмный 3D-монстр (`ink-grin-monster.js`, `createInkGrinMonster`): худое длинное чёрное склизкое тело, вытянутый череп, глаза в чёрных ямах с тонкими белыми кольцами разного размера, широкий оскал до глаз, длинные кривые зубы со щелями, длинная отвисшая челюсть, морщины на лбу, нос-дырка.
- Челюсть на заднем шарнире с пружиной: медленно разевается, резко щёлкает, мелко жуёт; видны глотка и язык.
- Действия (`userData.play(name)`, сами идут по очереди): `bite` — бросок, голова раздувается, пасть растягивается почти до пояса и захлопывается; `jump` — присед, взлёт, тяжёлое приземление; `strikeL` / `strikeR` — удар лапой с когтями; `grab` — схватить двумя лапами; `eyes` — зрачки-точки бегают в разные стороны, каждый глаз сам по себе.
- Жизнь без действий: следит глазами и головой за камерой (`userData.lookTarget`), наклоняет голову, изредка дёргается, дышит.
- Сцена (`scene.js`): темнота, свет только на лице, мёртвые деревья и туман; эффект старой плёнки одним GPU-шейдером (мягкий фокус, хроматика, зерно, виньетка, помехи на щелчке — `userData.pulse`); тяжёлая запаздывающая камера, отъезжает, когда пасть растёт.

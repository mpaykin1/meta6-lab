# INK · Ночной перегон — игра владельца (только читать)

Хоррор-скример: ночь у железной дороги, фонарик, монстр «Чернильный оскал» подкрадывается в темноте, мимо проносится ночной экспресс.
Источник: Claude, 15–17.11.2026; артефакт владельца https://claude.ai/artifact/U1DgRBXLAUtxnf51C4y4sK (версия 17.11: без тряски, стук колёс издалека, монстр целиком в кадре, бегающие глаза).

- `index.html` — вся игра в одном файле (автономный HTML, работает без интернета).
- `src/` — те же исходники в читаемом виде: `scene.js` (игра), `audio.js` (звук), `ink-night-train.js` (поезд); монстр — `reference/ink-grin-monster/`, рендер акварели и Three.js — `reference/ink-fallen-guardian/`.
- `zastavka-black-train.jpg` — заставка владельца «BLACK TRAIN» (17.11). По ней в боте ассетов заказ `asset-packs/incoming/black-train/`.

Правила: эту папку не менять (меняет только Claude по слову владельца). Новые ассеты — в паке, а не здесь.

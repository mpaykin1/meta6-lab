## Что принято
- Объёмный акварельный паровоз с вагонами (`ink-steam-train.js`): живые шатуны, крутятся все колёсные пары паровоза и вагонов, пар из трубы.
- Железная дорога в акварельном мире: ели, берёзы, камни, навес, фонари (из `../ink-fallen-guardian/ink-objects.js`).
- Рендер и шейдер акварели — из эталона «Павший великан» (версия без паттернов), общий GPU-шейдер, без проходов обводки болтов.
- Меню ☰: весь поезд / паровоз крупно / путешествие / стоп / чёрно-белая акварель; вращение пальцем и мышью, масштаб колесом или двумя пальцами, пробел — стоп.

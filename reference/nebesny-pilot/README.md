# Небесный пилот — эталон стиля «спрайт-стакинг» (только читать)

Источник от владельца (16.11.2026): Claude-артефакт https://claude.ai/code/artifact/025aa874-0c82-4e72-ae5f-39d20e9802d5 — файл байт-в-байт (sha256 3a8cb439…c89c9, 258 строк, Canvas 2D, без внешних библиотек).

Игра: вид сверху, реактивный самолёт летит над морем, пролетает золотые кольца (комбо, ускорение), острова и облака под ним; камера поворачивается за самолётом; музыка из аккордов, звон колец растёт по нотам.

Что такое спрайт-стакинг здесь: объём собирается из стопки плоских пиксельных срезов, нарисованных снизу вверх со сдвигом на 1 px по высоте и повёрнутых вместе с камерой.
Ассеты эталона (перечень из кода):
- самолёт `JET` — 13 срезов 32×32 (шасси, фюзеляж, крылья с огнями, кабина со стеклом, хвостовое оперение) + тень `JSH`;
- острова `buildIsland(seed)` — 4–6 ярусов-срезов (песок, 3 оттенка зелени с травой-крапинками, скалы, снег), мелководье вокруг, бесконечно по сетке `islandAt`;
- облака `buildCloud(seed)` — 8 срезов из «пуфов», светлеют кверху, + тень на море;
- кольца `RING` — золотое кольцо-цель с пульсацией;
- море `SEA` (узор), блики `SPK`, зерно `GRAIN`, следы-инверсии `trails`, частицы `parts`.

Правила: эталон не менять. Новые ассеты — в `asset-packs/incoming/nebesny-pilot-plus/` (формат — SPEC.md §SPRITE-STACK), игра с ними — отдельный файл-копия (НЕ ЛОМАТЬ РАБОЧЕЕ).

Рабочие исходники: `underwater-sumerek/` (Под и над), `ashen-sumerek/` (Сумерки и пепел, актуальная v5 с чёрным пепелом и рябыми облаками).

Правила:
1. Эталоны только читать. Развитие — в рабочих папках, отдельным PR, на свежем main.
2. В `ashen-sumerek/` правятся `ash_*.js`, `ashen_core.js`, `pack_ash.js`, `patch_ash.py`; `index.html` НЕ править руками — только пересобирать `python3 patch_ash.py` (CI проверяет, что он воспроизводится).
3. Нужен новый эталон — добавить новый файл и строку в SHA256SUMS отдельным PR по слову владельца, старые не менять.

Эталон `sumerki-i-pepel-owner-20261108-fdc87038.html` сохранён побайтно без изменений. Собственные пиксельные спрайты/атласы встроены в HTML; движок импортирует Three.js r160 и постобработку через внешний CDN, шрифт Pixelify Sans — из Google Fonts. Для запуска нужен доступ к CDN. Права сторонних библиотек/шрифтов следует учитывать отдельно.

# Туманные шпили — ассет-пак (эталон качества для новых ассетов)

Источник от владельца (13.11.2026): Claude-артефакт https://claude.ai/code/artifact/4b776199-6f2b-4e38-90d8-ab9f006eb064 («Туманные шпили — ассет-пак (Copy)»).
Файл взят байт-в-байт из исходного артефакта c215426d-b097-4a86-b28e-690ce6f45685 (sha256 2a4141fe…fae3b): та же страница, 515 строк, отличается только надписью «(Copy)» в заголовке вкладки.

Что это: одна страница, 26 живых ассетов (2D = 17, 2.5D = 9), всё рисуется шейдерами Three.js r128 (CDN cdnjs, MIT) и процедурными холстами:
небо и световые столбы, туман, обелиск-гигант, стены-исполины, ярусные шпили, мачты-иглы, купол, город на склоне, руины у воды, зеркальная вода, блики, розовые врата,
летун в плаще, плащ-ленты, клинок и дуга удара, огонёк и след, багровый зверь, бледная маска, светящиеся челюсти, розовые щупальца, взрыв врат, искры, осколки-лепестки, дождь, пыль, кино-обработка.
Список в коде: `window.__PACK__` (id, название, 2D/2.5D, режим, камера). Режиссёр: полёт → бой → взрыв → падение → площадь → подъём. Меню ☰ справа сверху.

## Правила
1. Эталон только читать. Новые ассеты — в `asset-packs/incoming/<имя>/` (копия + новые пункты в `__PACK__`), все 26 прежних остаются (потеряно 0).
2. Стандарт качества (SPEC.md, ГЛАВНЫЙ ПРИНЦИП): эффекты и техники любые; новый ассет — не хуже ассетов этой страницы.

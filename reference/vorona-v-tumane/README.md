# Эталон «Ворона в тумане» — рисунки владельца (только читать)

Новая игра владельца (17.11.2026). 3D-моделей нет и не будет: игра собирается из плоских нарисованных картинок, которые стоят в 3D-сцене с туманом (2.5D, вид сбоку или чуть сверху, параллакс).

| файл | что | стиль |
|---|---|---|
| `vorona.png` | ворона в полёте, 1254×1254, прозрачный фон | акварель, тонкий коричневый контур, серо-фиолетовые и тёплые бурые пятна, мягкая фактура бумаги |
| `sushchestvo.gif` | существо на четырёх лапах, 315×311, 16 кадров анимации | серая скульптурная лепка, тощее тело с позвоночником, ноги-протезы с механикой, длинные когти |

Это стиль для всех новых ассетов этой игры: ассет должен выглядеть как нарисованный той же рукой (акварель + контур для живого мира, серый скульптурный хоррор для существ тумана).
Оригиналы не менять. Ассеты кладутся в `asset-packs/incoming/vorona-v-tumane/`.

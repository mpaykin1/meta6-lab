## Исправлено в этой ветке

1. Repair Bot: недоступные tracked JSON больше не пропускаются; ссылки в предках отклоняются.
   При неисправимом JSON предварительная проверка запрещает весь набор планируемых правок.
2. ASSET CHECK: до извлечения ZIP проверяются пути, дубли имён, ссылки, шифрование,
   суммарный распакованный размер (100 MiB) и число записей (4096).
   Повреждённый/отсутствующий ZIP возвращает код 2; временная папка убирается автоматически.
3. Охота на мутантов: исходный набор тестов должен проходить до внесения поломок.
   Иначе возвращается BASELINE_FAILED, а не вымышленный успех всех мутаций.

Старые тесты не удалялись и не ослаблялись. Новые проверки используют изолированные fixtures.
Ремонтник не исправляет произвольную игровую логику: существующая функция — ремонт синтаксиса JSON.

## Подтверждённое ограничение защищённого ядра

`checkGame` с `bot.json: {"viewports":[],"skipChecks":["noRepeat"]}` возвращает
`{"ok":true,"runs":[]}` без открытия игры. Воспроизведено на исходном ядре с Chromium 141.
Это ложный успех. `scripts/meta-bot` защищён правилами AGENTS.md; исправление ядра
передаётся через DLYA_CLAUDE.md, без обхода checksum/охранника.

Наличие Markdown-промпта не доказывает, что соответствующий внешний ИИ запущен.
Функции промптов и внешние почасовые задания нельзя объявить исправными по локальным unit-тестам.
GitHub Actions на этой ветке нужно оценивать отдельно по текущему SHA.

# БЕЗ ПАТТЕРНОВ — обязательный закон графики META GAMES

**Решение владельца: 13.11.2026.** Графика должна сохранять природную нерегулярность при движении камеры.
Визуально заметные одинаковые косые волны, обои, квадратная плитка, ряды идентичных деревьев,
облаков, камней, волн и циклически повторяющиеся звуки не принимаются.

## Запрещено

1. Использовать для пятен, цвета, альфа-слоя и пигмента сумму двух или более `sin/cos` от
   `dot(worldPosition, constantVec)`, `position` либо `uv` с неизменной частотой.
2. Размножать маленькие текстуры `repeat > 2` без независимых вариаций на крупном масштабе,
   неодинакового вращения, смешивания или маскировки швов.
3. Использовать один октавный шум как единственный источник ландшафтного или акварельного рисунка.
4. Заполнять сцены сеткой одинаковых экземпляров с тем же вращением, масштабом, цветом и фазой.
5. Повторять звуковой сэмпл по циклу с всегда одинаковой громкостью/паузой без мотивировки.

## Правильные приёмы

- 3D value noise или simplex, **2–3 октавы** с разными масштабами: крупные разводы + средние + зерно.
- **Domain warp**: небольшое шумовое искажение координат до вычисления пигмента.
- Индивидуальный seed для объекта и устойчивое к движению камеры мировое пространство.
- Медленный дрейф времени, без мерцания и случайного изменения seed на каждом кадре.
- Текстуры: неплиточное наложение, многомасштабный macro-variation, случайный поворот, blend.
- Объекты: bounded jitter позиций, размеров, углов, цвета и формы; не ломать коллизии и путь героя.
- Звук: нерегулярные паузы, мягкая вариация тона/громкости и несколько разрешённых вариантов.
- GPU-шейдеры для покадровой текстуры, **никакого CPU-цикла по пикселям** при новом эффекте.
- Не изменять принятые палитры, толщину линий, форму обводки и художественный стиль игры.

## Примеры

**Плохо:**
```glsl
float a = sin(dot(vWorld, vec3(1.73, 2.11, .87)));
float b = sin(dot(vWorld, vec3(-2.37, .91, 1.41)));
float blot = (a + b) * .5;
diffuseColor.rgb *= blot;
```

**Хорошо:**
```glsl
vec3 p = vWorld + seedOffset;
vec3 warp = vec3(noise(p*.11), noise(p*.11+7.), noise(p*.11+19.)) - .5;
float pigment = fbm(p*.27 + warp*2.6); // fbm: 3 разных масштаба
diffuseColor.rgb = mix(paperColor, originalPigmentColor, pigment);
```

**Плохо:** 64 дерева с одинаковыми `rotation.y=0`, `scale=1` в прямоугольной сетке.
**Хорошо:** тот же парк с устойчивым seed, небольшими отклонениями размера/поворота/цвета и без ломки прохода.

## Механический контроль

`scripts/visual/verify-no-patterns.mjs` блокирует доказанные повторы в изменённых файлах
и `scripts/visual/mutate-no-patterns.mjs` проверяет три независимые мутации, включая обход через переменные.
Браузерный спектральный контроль сравнивает три разных места в каждой игре; сильный
ненулевой пик проверяется после маскировки HUD. Пороги калибруются на негативном
и исправленном INK; без чисел не объявлять визуальный PASS. Каждое новое пропущенное
нарушение — ловушка в сканере и запись в OSHIBKI.md.

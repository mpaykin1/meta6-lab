# ТЕЛЕФОН БЕЗ ТОРМОЗОВ — лимиты нагрузки на видеокарту телефона (обязательно, все игры, все ИИ, 24.11.2026)

Пароль `tormoza`. Правило владельца после разбора тормозов **Bullet Car 1.2** на Playgama (592 запуска → только 267 игроков дожили до 30 секунд). Цель: эти тормоза больше не повторяются ни в одной игре МГ, МГЛ и Playgama. Действует вместе с [VIDIMO_I_EKONOMNO.md](VIDIMO_I_EKONOMNO.md), GRAF и [PLAYGAMA_RETENTION.md](../07-publikaciya-playgama/PLAYGAMA_RETENTION.md).

Главное: **картинку делает атмосфера, а не количество работы видеокарты.** Тот же вид собирается дешёвыми приёмами.

## Что было в Bullet Car 1.2 и чем это заменять

| № | Ошибка (так нельзя) | Как надо |
|---|---|---|
| Т1 | 18 настоящих ламп (фонари ящиков, кабина, приборы, кузов, вспышка выстрела, фальшфейер…) — каждая считается для каждой точки каждого кадра | **Не больше 4 ламп** на сцену (обычно: 1 солнце/луна + 1 небо + до 2 важных, например фары). Остальной свет — **светящиеся пятна**: спрайт с `AdditiveBlending`, emissive-материал, свечение через bloom. Вспышка выстрела — спрайт, не лампа |
| Т2 | 7 ламп с силой 0 «на потом» — они всё равно стоят в сцене и стоят столько же | Выключенную лампу **убирать из сцены** (`remove`/`visible=false` до компиляции шейдера) или одну лампу переносить с места на место. Число ламп в сцене не менять во время игры (каждая смена = пересборка шейдеров = рывок) |
| Т3 | Зеркало заднего вида рисует весь мир второй раз каждый кадр | **Сцена рисуется 1 раз за кадр.** Зеркало/второй вид/портал — маленькая картинка (≤256×128), обновлять раз в 3–4 кадра, без частиц и дальних объектов, или подделка: заранее нарисованная картинка дороги + силуэты |
| Т4 | ~270 отрисовок, ~250 000 треугольников, 1 369 отдельных объектов | **≤150 отрисовок и ≤150 000 треугольников в кадре.** Одинаковое — одним `InstancedMesh`, неподвижное — склеить в одну геометрию (`mergeGeometries`), дальнее — проще (LOD) или силуэтом-спрайтом |
| Т5 | Каждый кадр в видеокарту уходило ~600 КБ: позиции всех 8 500 кусков леса и перегиб земли под холмы | **≤64 КБ геометрии за обычный кадр.** Лес записать в видеокарту один раз; движение/качание/холмы — в вершинном шейдере по `uTime` и `uOffset` (сдвиг мира — одна uniform-переменная). Обновлять только появившийся новый кусок мира |
| Т6 | Большая текстура грязи на стекле перезаливалась каждый кадр, экран навигатора — несколько раз в секунду | **≤128 КБ текстур за обычный кадр.** Грязь, капли, износ — шейдер поверх постоянной текстуры (маска × `uDirt`). Экраны-приборы — маленький canvas и обновление только при изменении |
| Т7 | Тени в реальном времени (каждая тень = ещё одна отрисовка сцены) | Тени — запечённые тёмные пятна под объектами (спрайт), затемнение в текстуре. `shadowMap.enabled = false` |
| Т8 | Попиксельная работа процессора (`getImageData`/`putImageData` в каждом кадре) | Только шейдеры (правило владельца: никаких циклов по пикселям на процессоре) |

Пост-обработка (зерно, глитч, хроматика, виньетка, bloom) разрешена: это несколько проходов по одному прямоугольнику экрана, не перерисовка сцены. Цель пост-обработки — 80% разрешения экрана, `setPixelRatio(Math.min(devicePixelRatio, 1.5))`.

## Бот-замерщик — проверка, а не обещание

Бот: [`scripts/telefon-bez-tormozov.mjs`](../../scripts/telefon-bez-tormozov.mjs). Открывает игру в телефонном окне 390×844, нажимает как игрок (тап, Enter, пробел), 5 секунд считает работу видеокарты (каждую отрисовку, лампы в шейдерах, выключенные лампы, перерисовки сцены, отправку геометрии и текстур, тени, попиксельные операции) и печатает OK/FAIL по каждому лимиту. Работает и с файлом, и с адресом игры (в том числе Playgama: замер идёт внутри iframe игры).

```
node scripts/telefon-bez-tormozov.mjs путь/к/index.html            # новая игра: все лимиты обязательны
node scripts/telefon-bez-tormozov.mjs старая.html --json base.json # замер «было»
node scripts/telefon-bez-tormozov.mjs новая.html --baseline base.json  # старая игра: не хуже прежнего
```

1. **Каждый PR** с изменённой WebGL-игрой проверяет [`telefon-bez-tormozov.yml`](../../.github/workflows/telefon-bez-tormozov.yml). Новая игра — все лимиты. Старая игра, которая уже была тяжелее лимита, — «старый долг» (OLD): правка проходит, только если ни один показатель не стал хуже больше чем на 10%, а при ближайшей работе над игрой долг чинится.
2. **Перед публикацией и обновлением на Playgama** — бот строго, без `--baseline`: ИТОГ PASS. С FAIL на Playgama не загружать. Ссылку владельцу — только после PASS (вместе с ССЫЛКА = 200).
3. **Ловушки:** [`automation/telefon-bez-tormozov/test.sh`](../../automation/telefon-bez-tormozov/test.sh) — хорошая сцена обязана пройти, сцена со всеми восемью ошибками Bullet Car 1.2 обязана упасть по каждому пункту. Сломанный бот = красный PR. Лимиты бота не ослаблять без решения владельца.
4. Нашёл превышение — сам чинишь приёмами из таблицы и только потом отчитываешься; картинку и стиль игры не терять (правило владельца: не удалять визуальный стиль). Доказательство — вывод бота «ИТОГ: PASS» в прогоне Actions (ссылка на прогон).
5. Swiftshader в боте считает ту же работу, что и телефон, но FPS в нём не показателен; FPS на настоящем телефоне — отдельная проверка.

# НЕ ЛОМАТЬ РАБОЧЕЕ — правило владельца (15.11.2026)

Касается всех игр (МГ и МГЛ), всех ИИ: Claude, ChatGPT, автозадач.

Цель: игру можно расширять и доделывать бесконечно, и при этом то, что уже работает, никогда не ломается.

## 1. Новое — только слоем поверх старого

- Рабочий код не переписывать и не удалять.
- Каждое изменение — отдельный слой (блок) в конце кода с подписью версии, например `// ===== v0.8 layer =====`.
- Слой «оборачивает» старую функцию: сначала вызывает старую, потом добавляет новое.
  ```js
  const updateOld = updateJourney;
  updateJourney = function(dt){ updateOld(dt); /* новое */ };
  ```
- Цифры (скорость, частота, туман, повороты) меняются умножением в новом слое (`DRIVE.curveStrength *= 1.25`), а не правкой старой строки.
- Если старое мешает — выключить его из нового слоя, а не вырезать.

## 2. Бот-проверщик после каждого изменения

- В игре должен быть отладочный вход `window.__<слой>.state` (например `window.__v8.state`) и команды для теста: запустить ситуацию, телепортировать, включить бессмертие.
- После каждого изменения бот в безголовом браузере (Playwright + Chrome) сам играет: едет, переключает роли, выходит из машины, собирает лут, запускает каждую ситуацию, открывает меню, перезапускает игру.
- Проверяется: **0 ошибок в консоли**, каждая ситуация доходит до конца, цифры в `state` такие, как ожидалось.
- Тест проверяет не только новое, но и старое (регресс): всё, что было в прошлой версии, тоже прогоняется.
- Есть ошибка → сначала исправить, потом сдавать. Сдавать с ошибкой нельзя.

## 3. Каждая версия — отдельный файл

- Версии хранятся отдельно: `игра-0.7.0.html`, `игра-0.8.0.html`… Старую не перезаписывать.
- В заголовке слоя и в `window.__<слой>.state.version` — номер версии.
- Всегда можно вернуться к прошлой рабочей версии за один шаг.

## 4. Отчёт владельцу

- Только ссылка, чтобы поиграть, и короткий список: что добавлено или изменено.
- Владелец проверяет игрой: если пишет только о проблемах — всё, что он не назвал, считается принятым.

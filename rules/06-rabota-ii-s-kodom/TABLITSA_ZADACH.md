2. **Статус ставит сторож, а не агент.** `ZADACHI watch` (каждые 30 минут) читает открытые PR **обоих** репозиториев `meta6` (МГ) и `meta6-lab` (МГЛ), включая mergeable_state и check-runs. Приоритет: слит → ✅ ГОТОВО; закрыт без слияния → ✖ ЗАКРЫТО; 🙋 НУЖЕН CLAUDE; mergeable_state=dirty → ⚔ КОНФЛИКТ с main (rebase на main и push); failure/timed_out/cancelled → ❌ КРАСНЫЕ ПРОВЕРКИ (открыть упавшую проверку, исправить и push); дальше время: 🔨 до часа, ⚠ 1–3 часа, 🛑 3–48 часов, 💤 после 48 часов. При mergeable=null после трёх запросов выводи статус по времени. Слово «готово» при неслитом PR сторож стирает.

4. **Не можешь закончить** — статус `НУЖЕН CLAUDE: <причина одной фразой>`; сторож его сохраняет.

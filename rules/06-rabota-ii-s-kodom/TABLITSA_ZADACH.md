1. **Взял задачу — сразу строка.** ChatGPT (любой чат и любая автозадача), взяв ЛЮБУЮ задачу по МГ или МГЛ, первым действием добавляет строку первой под шапкой таблицы и пушит в main meta6-lab только эту правку: `| взято | <задача простыми словами> | МГ или МГЛ | <кто: «чат ChatGPT» или имя автозадачи> | <ветка или —> | — | <время UTC, ГГГГ-ММ-ДД ЧЧ:ММ> | — |`. Без строки работу не начинать.
2. **Статус ставит сторож, а не агент.** Источник истины — GitHub API для открытых и закрытых PR МГЛ и МГ. Приоритет: ✅ ГОТОВО (слит → ничего) → ✖ ЗАКРЫТО (закрыт → ничего) → 🙋 НУЖЕН CLAUDE (не трогать) → ⚔ КОНФЛИКТ (`mergeable_state=dirty` → синхронизировать с main) → ❌ КРАСНЫЕ (`failure`, `timed_out`, `cancelled` → читать и исправлять логи) → 🔨 В РАБОТЕ (<1 часа → не мешать) → ⚠ молчит (1–3 часа → проверить) → 🛑 ЗАВИС (3–48 часов → продолжить ветку) → 💤 ЗАБРОШЕНО (>48 часов → продолжить либо доказанно закрыть). ✖ ЗАКРЫТЬ: дубль #N / заменён #N — закрывать только со ссылкой на актуальный PR. Сторож объединяет строки по ветке/PR с перечислением исполнителей, считает все статусы, печатает «Чинить сейчас» (⚔ / ❌) и «Толкнуть сейчас» (🛑).
3. **Задача без ветки** (настройка автозадач, проверка, ответ): закончил — сам замени статус на `ГОТОВО: <ссылка-доказательство>` (коммит, прогон Actions, issue). Без ссылки сторож считает задачу зависшей.
4. **Не можешь закончить** — статус `НУЖЕН CLAUDE: <причина одной фразой>`; сторож его сохраняет.
5. **Строки не удалять и чужие не править.** Не записал задачу — сторож сам добавит её из открытых PR с пометкой «сам не записал»; это считается нарушением правила.
6. **Зависшее продолжают, а не начинают заново:** строка «ЗАВИС» с веткой — следующий запуск продолжает с последнего коммита этой ветки.

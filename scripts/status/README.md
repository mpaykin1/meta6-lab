# Короткий статус
STATUS.md хранит SHA последнего содержательного коммита main; служебный коммит, меняющий только STATUS.md, исключается из SHA из-за невозможности записать SHA коммита в его собственное содержимое.
GitHub Actions не запускает новые workflow от push, выполненного штатным GITHUB_TOKEN, поэтому периодическая сверка включена каждые 15 минут.

# SYMPHONIA — основа игры «Адажио» (исходник владельца)

Источник: артефакт владельца «Адажио» `6ee19e68-cfd3-409d-b4a1-040ea0b04305`, версия `1795524169-bcac` (24.11.2026).
Положил Claude по просьбе владельца. С этого файла автозадачи строят новые миры и главы SYMPHONIA.

## Что где лежит (без сборки — правишь и сразу работает)
| Путь | Что это |
|---|---|
| `index.html` | **Игра и её исходник в одном читаемом файле** (~1000 строк): Three.js (с CDN), шейдеры, композитор музыки, бой, зал, двор. Открывается прямо на GitHub Pages. |
| `a/` | Все ассеты: 78 спрайт-анимаций (`*.webp` + `manifest.json`: кадры c×r, f), объёмные модели двора `ext/`, оружие `st/`, пианистка. Новый спрайт: положить `a/<имя>.webp`, добавить запись в `manifest.json` и имя в список `HALL_SPR` или `EXT_SPR` в `index.html`. |
| `bots/` | Боты-проверщики (Playwright): `bot_auto.py` (вся игра до финала, `mobile` — телефон), `bot_music.py` (12 жанров и 12 переходов, гармония), `bot_deco.py` (предметы зала и двора), `bot_ctrl.py` (сенсорное управление, дверь во двор). |
| `versions/` | Перед каждой заменой `index.html` копия старой версии кладётся сюда как `vNNN.html` (файл маленький, ассеты общие). |

## Как проверить
На GitHub боты запускаются сами на каждом PR, который меняет эту папку (проверка ETALON BOTS). Бот упал — PR красный.
```
pip install playwright && playwright install chromium webkit
python3 symphonia/game/bots/bot_auto.py mobile # 0 ошибок, кроме «GPU stall» предупреждений
python3 symphonia/game/bots/bot_music.py       # ERRORS [] ; доля диссонансов < 10%
# если сеть к cdn.jsdelivr.net закрыта: SYM_THREE=/путь/three.module.min.js (three 0.160.0)
```
Для ботов в игре есть `#bot` в адресе: `window.__bot` (hall, go, look, forceWave, shootAll, killV, musSet, decoTest, s — состояние).
Автономный файл одним куском (без интернета) Claude собирает отдельно для артефакта владельца; в репозитории он не нужен.

## Что уже есть в игре (не терять — правило НЕ ЛОМАТЬ РАБОЧЕЕ)
- **Двор усадьбы** (sprite stacking: ворота, фонари, фасад, купол, крылья, стены, туман) и **зал эха** (мраморный пол с отражением, колонны, свечи), дверь между ними в обе стороны.
- **Оружие** (6): костяной арбалет, арбалет с бирюзовым жалом, дробовик, пулемёт, малый арбалет, Фантом. Настоящие стрелы. Оружие меняется только подбором в зале.
- **Враги**: сгустки тени (в зале летят к роялю, во дворе — к её окну), Вендиго (8 ракурсов) приходит, когда музыка замолкает.
- **Предметы-награды за волны** (11): канделябры, часы, статуя, зеркало, лунный луч, арки, штора, люстра, ворона, окно, туман; во дворе со 2-го круга — беседка и ангел. Каждый даёт пользу, свою строчку сюжета и меняет музыку.
- **Композитор** (`/* ===== КОМПОЗИТОР` в `index.html`): 12 жанров (Увертюра, Ноктюрн, Адажио, Скерцо, Соната, Фуга, Токката, Реквием, Рапсодия, Фантазия, Сюита, Симфония), 12 переходов, темы ЕЁ и ЕГО заново на каждом круге. Жанр выбирает сюжет (`plotGenre`).
- **Правило гармонии закреплено в `harmo()` внутри `piano()`** — через неё проходит каждая нота: фальшивых нот нет, высокие ноты только из аккорда баса, диссонанс на 50% тише. Не обходить.
- **Управление на телефоне**: левый джойстик — идти, правый — только оружие (тап — выстрел), голова — пальцем по экрану; джойстики идут за пальцем.
- **Сюжет**: финал в зеркале (герой — Вендиго), рассказ от первого лица, круги 2, 3…
- **Телефон**: отражение в полу только нижней части зала (облегчённой копией), зал режется на куски по 6 м: за спиной не рисуется, дальше 8 м — облегчённая копия; адаптивное разрешение при просадке FPS; двор: верх/низ слоёв склеены, дальше 17 м — облегчённые копии моделей (каждый второй слой двойной толщины).
